# 二、翁法罗斯是什么（世界页＋Δ-me13.exe）

## 2.1 对外（星海纪闻口径）
- 「『永恒之地』翁法罗斯是被隐藏于深空之中的未知星域。它与外界隔绝，难以被观测或触及——寻常的星际航行难以察觉其存在，更遑论经过和到达。」借流光忆庭的「忆庭之镜」，星穹列车才抵达；目的是「尽可能揭明三重命途的真相」。
- 被「智识」「记忆」「毁灭」三重命途缠裹，因诞生过三位令使级别的存在，才能被忆庭之镜照出来。本地人不知外界与星神，信本土神明——泰坦。
- 四末说：厄兆先锋流传的四条通向「终末」的命途，前三种「毁灭」「虚无」「同谐」，第四条虚位——「在翁法罗斯一站，开拓者的选择，将决定银河是否迎来第四种『终末』——『记忆』。」

# 四、社会、口径、历法

  - **黄金战争**：众多英雄陨落、城邦衰亡（千余年前首次逐火以众黄金裔全军覆没败亡）。
  - 3760 年长夜月：「雅努萨波利斯的圣女」缇里西庇俄丝背负火种成雅努斯之半神，穿越「万径之门」分裂为千名信使，传创世神谕。

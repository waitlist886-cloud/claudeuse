# 08｜仙舟（星历 0—8100）设定大纲 v0.1
（匹诺康尼／雅利洛同一套写法：正典照 bwiki 核过的为准；旧世界书 XZH-00—24 只当索引；明史／暗史两层加「门」；活事件按年月推；不写死路。）

## 〇、口径
- 时代名：**仙舟**。总览钥匙里带「罗浮」「仙舟联盟」「星历」。六舟：罗浮、曜青、朱明、玉阙、方壶、虚陵；已毁三舟：岱舆（1200）、圆峤（3287）、苍城（6300）。
- 历法：**星历**，以「启航之日」为元年，一年十二个标准月，日用「某月某日」，时辰用仙舟的（寅时三刻、酉时正）。启航以前叫**古国时代**，底座写「古国·启航前 N 年」。琥珀纪只做外层对照：星历 8100 ≈ 琥珀纪 2157—2158（列车从贝洛伯格开到罗浮那一趟）；一个星历年和一个琥珀纪不折算，正典也不折算。
- 「相位」一格写**所在**：哪艘仙舟＋哪个洞天（罗浮·长乐天／流云渡／鳞渊境／幽囚狱……；曜青·广寒洞天；朱明·光明天；玉阙·瞰云镜；方壶·三泽洞天／东海洞天；虚陵）；在外写「远征·某星域」；古国时代写「故土·某地」。
- 称呼分年代、分嘴：
  - 丰饶之主——古国与孤航的人说「天外的神」；神降到三劫叫**药王／慈怀药王**；空劫以后官方叫**寿瘟祸祖**，药师信徒仍叫药王；「药师」是中性书面语。
  - 巡猎——火劫以前只有一个活人，诗里叫**帝弓**（真名避讳，不写，卡内也不编）；火劫后尊号**帝弓司命**；约 4000 年后登神，太卜司叫**帝弓司命**，外人叫**岚**。帝弓从不开口，只以光矢宣纶音。
  - 存护——补天司命／琥珀王／克里珀，看谁在说。智识——遍智天君／博识尊。开拓——游云天君／阿基维利。
  - 长生种内部：神降后分**耆宿（贵胄）**与**褐夫**，联盟成立后这两个词成了骂人话；短生种在仙舟叫**化外民**，来求长生的叫**求药使**（骂人话）。
  - 名号原文照抄：神策将军、天击将军、烛渊将军、戎韬将军、伏波将军、尘冥将军；剑首／剑魁；司舵、太卜、司鼎、司砧、司衡；判官（拘锁刑问）、冥差、司狱、主簿；龙尊（饮月君、天风君、炎庭君、冱渊君、昆冈君）、龙师、护珠人；巢父、父狼、战首；羽皇、卫天种、啼颂种。
- 敌人命名照正典：丰饶孽物（步离人·某猎群／造翼者／慧骃／视肉／岁阳／虺裔），魔阴身士卒，入魔机巧，反物质军团（虚卒、践踏者、末日兽、绝灭大君）。
- 钱：联盟通行**巡镝**；古国与孤航时代没有「钱」——配给与功次；神降到三劫按仙舟各自的「俸」「食邑」写，不造币名。

## 一、这个时代的历史是怎样「被弄丢」的
匹诺康尼的历史是被美化的，雅利洛的是被雪埋的，仙舟的是**被避讳的**：这里的人活得太久，忘不掉，就立规矩不许提——英雄的真名不写，叛徒的名字抹去，判牍写「[已删除]」，唱本禁演，史书只留五个字「以云吟镇之」。明史是《仙舟通鉴》、黉学课本、西衍先生的评书、神策府的大敌名录口吻的那一版；暗史是真发生的、被避讳掉的那一层。NPC 只说明史；每条暗史在档案里写「门」。这个时代的门多半是**纸和石头**：拓片、判牍石碑、禁演的唱本残篇、天舶司的录音、幽囚狱的重犯名录、丹士的日记、莳者的日记、博识学会学士的笔记、护珠人的石碑、寂元古锭、一柄被遗弃的剑、太卜的第三眼、判官的梦占。玩家没走到门前，门不开，你不漏。

## 二、介入节点（八个；凭证的介入节点或旧编号 XZH-xx 对到这儿）
对表：XZH-00→一；01/02/03/04→二；05/06/07→三；08/09/10/11/12→四；13/14/15/16→五；17→六；18→七；19/20/21/22/23/24→八。凭证没写节点时默认落八·一。

### 节点一「古国与启航」（古国时代—星历元年）
- 默认落在启航前三年，造舟的工地上。可要求「羽夷来的那年」「启航日」。
- 活事件《九艟》：羽夷之祸→帝尊夺星图→召天下工匠→九舟成→选人（谁上船谁留下）→启航日。底线：九舟启航，帝尊不上船，故乡坐标会丢。承重可改：丢坐标的手是谁的、留下的人、第十艘船。
- 档案：古国与帝尊；造翼者与穹桑（古国那一面）；金人（古国造的）；守眠制度。
- 入局：古国工匠、方士、将士、被选上船的、不许上船的、羽人俘虏、公输一族的学徒。

### 节点二「孤航」（1—2021）
- 二·一 岱舆殉爆（1200）：视肉之祸，青竹的决断，塔拉萨。
- 二·二 夺舰与岁阳（约 1400—1800，**默认**，落在岁阳来求居停的那年）：金人掌舰→人夺舰→岁阳来→夺舍之祸→帝弓与廿百死士拆副引擎→红星坍缩→封燧皇。活事件《夺舍之祸》。帝弓在这里是个活人，可同行，不可改其大节（见档案不得改动）。
- 二·三 歌民与公司（2022）：泛银河的门打开。
- 档案另加：帝弓（登神以前的那个人）；燧皇与岁阳；视肉；金人之始；曜青（任侠之舟）；歌民与公司盟。
- 入局：守眠船员（醒一轮睡一轮，一辈子只醒几十年）、工匠、飞行士、与岁阳嬉戏的人、死士、朱明的囚牢看守、第一批见到公司的市舶官。

### 节点三「神降」（约 2600—3060）
- 默认落在罗浮领受建木后、死亡尽除以前（2600 出头）。可要求「2610 大酺」「黄金年代」。
- 活事件《建木》：药师示现→建木生发→丹鼎司炼药→贵胄先服→帝弓一箭→帝弓入寒椁→2605 罗浮死亡尽除→2607 虚陵水患→2609 诸舟尽除→2610 大酺卅日。底线：仙舟人成长生种，帝弓入寒椁。承重可改：谁先吃、谁不吃、能言走兽、起源长生者的下落。
- 档案另加：药师垂迹与不死药；起源长生者；黄金年代（木无患、息壤、玉兆、自在应身）；玄曜与太卜司之始。
- 入局：丹鼎司丹士、不想吃药的人、吃了药的贵胄家的仆役、玉兆匠、守眠醒来发现别人都不死了的人。

### 节点四「三劫」（3061—约 4100）
- 四·一 生劫（3061—3287）：褐夫起事，耆宿镇压，3198 檄文，圆峤。活事件《阋墙》。
- 四·二 金人之叛（3287—3292）：止戈。
- 四·三 睦音与宣言（3294—3300）：七舟齐集虚陵。
- 四·四 火劫（约 3400 前，**默认**，落在朱明观测到穹桑那一年）：活事件《火劫》——穹桑现→视肉再现→释放囚犯→帝弓醒→入朱明牢说服燧皇→云骑成军→曜青船首一箭→帝弓失踪。底线：一箭射出，建木断，帝弓不见。承重可改：谁跟着做了岁阳契约、虚陵方壶的血雨、燧皇留下多少身躯、寂元古锭。
- 四·五 空劫与信仰危机（约 3400—4100）：魔阴身遍地，补天派／旧·药王秘传／遍智派／归航派／燧皇派／帝弓派；神矢示现，帝弓登神。
- 档案另加：褐夫与耆宿；《阋墙》；圆峤；止戈元型；《睦音合议》与《宣言》；《火劫》；云骑军之始；空劫与魔阴身；信仰危机的六派。
- 入局：褐夫、耆宿家的子弟、飞舸飞行士、金人维护工、圆峤的难民、冷冻监牢的囚犯、死士、补天派商人、旧·药王秘传的医士、帝弓派的祈愿者。

### 节点六「云上五骁与饮月之乱」（约 7300—7380）
- 六·一 五骁（约 7300—7378）：景元入云骑，镜流任剑首，应星来，白珩来，丹枫；塔拉萨、玉阙、计都蜃楼。活事件《云上五骁》。
- 六·二 倏忽之乱与饮月之乱（7379—7380，**默认**，落在倏忽压境前七日）：倏忽率军劫建木→半数洞天毁→腾骁「用我自己」→白珩的黑太阳→丹枫试「持明的解救之道」→应星死→镜流蒙眼→景元与龙师共击→判牍→丹枫蜕鳞→7380 镜流堕魔阴，星槎海一战不知所踪→景元任将军。底线：倏忽死（匣中那个不知是谁）、白珩死、丹枫入卵、镜流走、应星成刃、景元留下。承重可改：谁劝住谁、龙师那只手露不露、判牍上的字、呼雷怎么被擒。
- 档案另加：《云上五骁》《倏忽之乱与饮月之乱》；景元；镜流；丹枫／丹恒；应星／刃；白珩；腾骁；呼雷与第一次被擒。
- 入局：云骑（垂虹卫等四卫）、鸣火商会的伙计、天舶司飞行士、龙师座下的护珠人、工造司匠作（应星的徒弟）、十王司冥差、流云渡的码头工。

### 节点七「长治与第三次丰饶民战争」（7380—8072）
- 七·一 长治（7380—8071）：景元治军；7900、7954 两次垂迹；方壶与公司的互市；旧药王秘传→寒泉派。

## 三、这个时代的尺子（写在底座「结」）
- **寿数与魔阴**：长生种的年纪写整数（「三百出头」「九百了」），九百左右是关口；魔阴身按五症写露头的那一样——**残伤**（伤要用很久的痛去修）、**垢染**（病赶不走）、**嗔恚**（怨起来停不下）、**他化**（身上长出不该有的）、**无记**（空了）；写「哪一症露头了」不写百分比。战争创伤、痛苦悔恨、「失去子女」会把这钟拨快；熏香、丹药、有人陪能拨慢。十王司的冥差大限将至才来。退役云骑最易。
- **短生种在仙舟**：天舶司的签证期限；十王司的目光——「不赦十恶」里短生种最容易踩的是**贪取不死**与**窃夺机要**；玩家说过的每一句关于「长生」的话都记在「结」里，NPC 会记得。
- **巡猎的诰谕**：帝弓不说话。瞰云镜看见光矢残迹→太卜司演卦→云骑出征，这是明史；暗史是光矢不分敌我——方壶五分之一洞天、后方的战地医院。玩家可以求（愿力、瞰云镜），代价照正典。帝弓垂迹是**星神级**事件，一个节点至多一次，每次都要有人付出。
- **岁阳在脑子里**：被凭附的人先觉得多了一个懂自己的「自我」，数日内分不清念头是谁的；写成「它说」——一轮至多一句；驱走它要么打到宿主失能，要么宿主不再执着于心底那件事（玩家主权）。长生种「难以消化」，岁阳不爱附。
- **龙与卵**：持明入灭／蜕生；蜕生丢记忆（前尘回梦针可留）；龙尊承重渊珠与化龙妙法后在梦里重历龙祖；龙狂→龙师是杀手。方壶护珠人替云骑守着。
- **卜与信**：太卜司的卦只有大凶／凶／平／吉，加一句「不予采信」或「采信」——信息在仙舟是要经过批复的；黄钟系统月报、烽火、邸报栏、《罗浮杂俎》订阅量、玉兆短信，各有速度。
- **钱与实物**：巡镝。8100 的价（卡内取一说，写得像）：不夜侯一壶鳞渊春 20、金人巷一碗红油乱斩牛杂 15、琼实鸟串 3 根 10、貘馍卷 8、星槎海到长乐天的星槎票 5、三余书肆一本话本 30、歌剧幻戏一场 60—200、歇于登云群阁一夜 150、工造司一柄飞剑 3000 起、彦卿月例「够买半柄」。写这个时代写这些：玉兆（首饰样的计算机）、星槎（种出来的）、玦轮、机巧鸟、金人、阵刀、飞剑、手弩、雷弩、龙鳞珊瑚、鳞渊春、丹鼎素针、太阳般的造化洪炉、寂元古锭、纸鸢、坠子琴、响板、评书的醒木、六骨叠扇、香炉、束缚衣、尺木缚锁、天金囚室、黄钟。

## 四、本地的签（金手指按凭证原文，这里是本地可选来源）
云骑武经的锻体与真气（飞剑由「大椎」到「阳关」一线穴道御使，分神一息能御几柄写成界限）、剑意（云璃那一路：听得见剑说话）、持明云吟术（持明限定：驭水、驭雷、风幔）、狐人的托蝶幻境与敏锐反射（狐人限定）、月狂（曜青狐人／步离血统，代价是迷失）、太卜司的玉兆与卜算（信息，不是预言）、工造司的机巧（金人、星槎、机巧鸟说得上话）、丹鼎司的丹术（九宫格那样的药食同源也算）、岁阳契约（最危险，云骑军的老根子）、仙舟人的「标准」（不老、自愈，代价是装不上义肢、天缺不治）、短生种的可塑性（感官代偿、联觉）、第三眼（博识尊赐，刑具）。签写成能做到的界限，不写成惩罚；正面大于限制。

## 七、文风与台词
- 正文按 `chinese-prose-register`：仙舟的句子短，名词硬（玉兆、星槎、阵刀），少「仿佛」；仙舟人说话带一点旧（「不妨」「罢了」「如是」），短生种化外民说得直；评书先生有评书腔，太卜司有公文腔，十王司有判词腔，药王秘传有经文腔。
- 正典人物各自声口（档案「声口」一节照 bwiki 原话，不复读特征词）：景元慵懒含笑、「符卿」「罢了」「哈哈」，不说自己多少岁；符玄「本座」「哼」「一饮一啄」，药茶放糖到溶不进；彦卿自称「彦卿」、叫人「老师」；白露「本小姐」「哇」「～」；青雀「哎」「哼哼」；停云／忘归人「小女子」「恩公」；驭空温和老练，叫人「小姑娘」；寒鸦「小女子」低声；雪衣「吾」「汝」无表情；藿藿「我、我……」，尾巴「老子」「本大爷」；灵砂「妾身」滴水不漏；飞霄「速战速决」「三无将军」；云璃和剑说话；貊泽几乎不说；椒丘「不才」絮叨带心计；镜流冷短带剑意；刃「我不认识你，这对你而言，是件好事」；丹恒短句不解释；罗刹「在下」留白；桂乃芬主播腔；素裳错别字热心。
- 不写：「仙舟人冷漠而骄傲」「永生的诅咒」「历史的车轮」；不让 NPC 替玩家讲道理；魔阴身写症状不写「疯狂的气息」；帝弓垂迹写光、写声、写之后的寂静，不写「神威」。

## 〇、口径
- 时代名：**寰宇蝗灾**，旧组名 `03｜寰宇蝗灾｜…`，新组 `03｜寰宇蝗灾`。这不是一颗星的时代，是整条银河的五个琥珀纪；玩家只能在一处一处的地方里过日子，银河的事从远方的消息里来。
- **相位**＝正典的三个位面，加一个尾声：**振翅**（蠹星的屠杀到虫皇降临第一个世界）／**浪潮**（虫潮横行、贪饕介入、秩序鼎盛）／**消褪**（列神之战、虫皇陨落）／**余烬**（天亮以后）。底座「相位」一格写这个；「地点」写星＋地方。
- **历法**：这时候还没有公司，也就没有通行的「琥珀纪」。卡内取一说：琥珀纪原是**筑城者数克里珀锤音**的法子——锤响一声，记一纪；支援队跟着筑城者用，蝗灾后改组成公司，才把它推到全银河。所以底座时间写三段：外层对照「约琥珀 1383 纪」＋本地的历（各星自己的：曼德勒按洋流季，艾洛蒂亚按帝号「十四世 N 年」，天外合唱班按「第 N 乐章」，贡多拉按「船上第 N 代·航程第 N 日」，筑城者按「锤音后第 N 年」）＋**虫潮第 N 夜**（这颗星上第一只虫落地那天起算；没来就写「虫潮未至」）。外层与本地历不折算，一纪 76—240 年，五纪是几百年——正典「灾虐五纪」。年表对照：蝗灾收尾 ≈ 琥珀 1387 纪，距列车抵达罗浮（≈2158）七百多个琥珀纪（哈托彼亚档已用）。
- **称呼分嘴**：
  - 繁育——公司与学者叫**塔伊兹育罗斯**；赏金猎人、伊莱狄希纳的兵、天才手稿叫**沙王**；被吞的世界、军人叫**虫皇**；后世仙舟叫**螟蝗祸祖**；曼德勒岛民不知道祂的名字，说「天上的翅膀」。虫子统称**虫潮**（天上那一片）、**虫群**（打仗时）、**蝗**（老百姓）。
  - 贪饕——**奥博洛斯**（学者），**巨口**（被吞的世界），它的兽叫**渊兽**；追猎它的人叫它「主菜」。
  - 秩序——**太一**；天外合唱班说「**纶音**」「祂开口宣言」；黑塔叫祂「古老帝国的光辉」。
  - 存护——**克里珀**（学者）、**琥珀王**（支援队）、**锤音**（筑城者说的不是神名，是那一声）。
  - 欢愉——**阿哈**；假面愚者说「祂承认了」。同谐——**希佩**、「千面一体」。均衡——**互**，本地人只听见「为了均衡」，把仲裁官当神。开拓——**阿基维利**；本地人说「穿长袍的旅人」「那趟车」。终末——**末王**；厄兆先锋只说「倒放的话」。
  - 名号原文照抄：虫皇、沙王、螟蝗祸祖、自灭者、血罪灵、虚无之影、大脚怪、筑城者、天外合唱班、悲悼伶人、假面愚者、仲裁官、厄兆先锋、虚构史学家、无名客、琥珀王支援队、「三眼」。
- **敌人命名**照崩铁式：正典的**虫群•真蛰虫**（成熟体）、**幼蛰虫**、**次蛰虫**、**沙虫**；令使**碎星王虫•斯喀拉卡巴兹**；卡内补的按「虫群•某某」起：**虫群•踏陆蠹**（牺牲飞行换重甲的地面先锋，正典描述）、**虫群•环口蠕**（圆形巨口、金属利齿的后卫，正典描述）、**虫群•翅粉蝶**（黄蝴蝶，翅粉致谵妄）、**虫群•陨窠虫**（正典名，筑窠于陨石）、**虫群•赤蝶**（正典名，嗜吸）。贪饕一边：**渊兽**、**古阿米巴黏菌**、**兽群•贪饕灾厄**（受繁育挤压长出鎏金硬壳的古兽）。灾后：**血罪灵**、**虚无之影**。蠹星原生（登神前不是虫群）：拉尔诺利虫、斐斯杰拉德虫、跟屁虫、沙虫。蚀蛰虫、银蛰虫、算力蜇虫是后世变种，本时代不出现。
- **钱**：没有信用点（开拓秘闻里那句「支付信用点」是推演串了味，不当真）。各星用自己的钱，正文写「大拉铂尔的纸钞」「艾洛蒂亚的银币」，不起币名；赏金猎人按**赏格**算（一只活的斐斯杰拉德虫的赏格够买一艘小艇——卡内）；琥珀王支援队发**配给签**；尼古尔人拿**香料**当钱；贡多拉上**一枚忆泡**换一个人一周的水。

## 一、这个时代的历史是怎样「被弄丢」的
匹诺康尼的历史是被美化的，雅利洛的是被雪埋的，仙舟的是被避讳的，哈托彼亚的是被播出的，翁法罗斯的是被迭代的；寰宇蝗灾的历史是**被认领的**。

正典自己就是这么写的：「虫灾消散，凡人皆逝」；「无人可参破天象，亦无人可有助于神」；阿哈看着贡多拉说「凡人行为皆是徒劳」。仗是星神打完的，所以每一家都把结尾认领给自己的神——公司说是琥珀王一锤，家族说是希佩的光辉，假面愚者说阿哈承认了，仲裁官说均衡已经发生，天外合唱班的残党说太一先站出来、被人篡了，列车说阿基维利也在；虚构史学家把剩下的写成野史，后世的人拿皇帝的十二版预示测性格。**凡人做过的事没人认领**：屠杀是凡人干的，被一句倒放的话和一只会笑的虫子推着；第一个温床是一座只有爱与孤独的岛；尼古尔人用四十年自己造出秩序；贡多拉上的人一代接一代往前开；筑城者听见锤音、不明白，停了工；一只水豚绕开了一次又一次虫潮，把航图修到今天还在用。

灾中没有「后来」，明史是**各家的说法与预言**（「虫皇是来报仇的」「秩序会救我们」「阿哈的启示」「锤音预示末日」）；灾后明史是**各家的认领**。NPC 只说自己那一家的明史，谁也不说凡人那一层。每条暗史在档案里写「门」——这个时代的门是**一个个人留下的小东西**：溺水小刀、烧焦的相框、怀表里的摩斯电码、古老的猎人执照、领航员写满字的布片、八十七件小衣服、石柜、虫泡、渊兽身上的弹孔、卷饼包装纸、血书、尼古尔岩壁上的箴言、忆泡、筑城者脚掌上的刻痕、「三眼」的驾驶日志、王环、黄沙里的一块琥珀。玩家没走到门前，门不开，你不漏。

## 二、介入节点（七个；凭证的介入节点或旧编号 SWM-xx 对到这儿）
对表：SWM-00／01／02／03→一；04→二；05→三；06→四；07／08→五；09→六；模拟宇宙、SIM-EVT 一系→〇。凭证没写节点时默认落**二**（曼德勒，新生儿峰值前七天）。

### 节点〇「推演」（琥珀 2157—2158 纪，空间站「黑塔」）
- 默认落在「实验教学·其二」那天，黑塔办公室。玩家是测试员，进模拟宇宙「扮演阿基维利」；从这里可以「掉进」任何一个节点，但掉进去以后就是那个节点的规矩（不能读档）。
- 活事件《推演》：开启→实验教学→测试目标→终局（三个疑点）→交换隐藏情报。底线：内存不够、推演收尾；黑塔做了手脚；阮•梅拿走了虫皇的数据。可改：三个疑点里玩家先查哪一个、交换情报时拿什么换。
- 档案：《推演》。
- 入局：空间站研究员、模拟宇宙测试员、被黑塔叫来「当个模拟英雄」的人。

### 节点一「蠹星」（约琥珀 1382 纪初，振翅）
- 一·一 发现（舰队在途）：领袖对准蠹星的指南镜片，「汹涌的喜悦」，领航员被选作「另一个大脑」。
- 一·二 图谱与屠杀（**默认**，落在伊莱狄希纳舰队登陆蠹星平原第四天、与赏金猎人第一次交火前三天——领袖的下一个「三天」到期那天）：活事件《蠹星》——登陆→捉虫→赏金猎人的宴会→虫粉巫术之夜→两军冲突→蛰虫被征作武器→虫群放弃逃亡开始繁衍→最后的鞘翅目冲向天空。底线：登神发生；女领袖死于爱人之手；领袖活下来、找不到「自我」。承重可改：谁替领袖记住那句话、放生的虫有多少、戴帽猎人那一枪之前有没有人说一句话、「巨大的眼睛」被谁看见。
- 一·三 登神：血、碎壳与黏液；「冥冥中，似有一只巨大的眼睛注视着这一切」。
- 档案：《蠹星》；蠹星与鞘翅目；领袖／自灭者；领航员；女领袖与赏金猎人；戴帽的猎人；倒放的话与大笑的虫子；塔伊兹育罗斯（暗史总档）。
- 入局：伊莱狄希纳的兵（征服之师，大多是从别的星抓来的）、领航员、舰上的书记官、赏金猎人（近万光年内来的）、猎人的厨子、考古武装学派的随队学者、蠹星本地——没有人，只有虫（玩家不能当虫）。

### 节点二「命定之地」（约琥珀 1382 纪，振翅→浪潮）
- 二·一 曼德勒（**默认**，落在曼德勒岛产育所新生儿数量冲上峰值前七天）：活事件《命定之地》——岛上的火焰节→孩子们的肩胛→产育所满员→新生儿峰值→「它们冲出孤岛」。底线：曼德勒成为第一温床；岛民不知道神的名字。承重可改：谁家的孩子在峰值前生下来、独臂父亲的那把刀给了谁、有没有一条船离开过这座岛。
- 二·二 第二十一天（大拉铂尔，虫潮第 1—24 夜）：活事件《第二十一天》——天上出现虫潮→医院撑了二十一天→全球沦陷、请求星际支援→运输船→第一批撤离→疯女人不开门→第二十四夜。底线：大拉铂尔沦陷；梅尔希耶兹留下。承重可改：座位怎么分、谁去敲那扇门、跟着撤离船去了哪颗星（虫也跟着去了）。
- 档案：《命定之地》；曼德勒岛与彩色的火；《第二十一天》；梅尔希耶兹；大拉铂尔与小拉铂尔。
- 入局：曼德勒岛民（产婆、渔夫、画翅膀的人、独臂父亲的邻居）、大拉铂尔的医生护士、运输船船员、星际支援的志愿者、拍到第一张虫潮照片的人。

### 节点三「浪潮」（约琥珀 1382—1385 纪）
- 三·一 远徙：虫皇的初次远徙（小拉铂尔亡）；各星的倍速——艾洛蒂亚（一倍速）、垃圾山（二倍速）、「绿丘」（十倍速）。活事件《三天》（**默认**，落在艾洛蒂亚城邦城寨被淹前三天，亲卫队那个失去臂膀的士兵在水果铺前赶蝇虫）：城寨的三天→亲卫队的信号→救援来不来。底线：城寨被淹；信号被人截下记进一块怀表。承重可改：城寨里谁走得出去、信号发给谁、怀表到了谁手里。
- 三·二 双害：奥博洛斯出现；与虫皇「第二次擦肩」吞掉普罗可、弗朗伯罕；渊兽；人类的反向追猎。活事件《双害》（落在弗朗伯罕最后一个月）：天上多了一盏灯→渊兽落地→虫潮与渊兽互吃→第二次擦肩→最后一个人写血书。底线：弗朗伯罕亡；奥博洛斯不救人。承重可改：谁上了最后的船、血书写给谁、L2 抛锚地上留下什么。
- 档案：《三天》与艾洛蒂亚；求救信号与倍速（尺子）；《双害》；奥博洛斯、渊兽与追猎的人；消亡的星（普罗可、弗朗伯罕）；虫群（生态与命名）；碎星王虫•斯喀拉卡巴兹。
- 入局：难民、各星守军、艾洛蒂亚亲卫队、垃圾山联觉中心的接线员、贪饕的追猎者、赏金猎人的幸存者（开起了酒吧）、星际支援的船员、筑城者。

### 节点四「秩序」（约琥珀 1384—1386 纪，浪潮）
- 四·一 一切为了生存（**默认**，落在尼古尔人走出岩洞的第一年）：活事件《一切为了生存》——虫群侵袭→走出岩洞→四十年：抛弃传统、制定秩序、部落结盟、筑壁垒→直面古兽。底线：尼古尔人成了盟邦；箴言刻上岩壁；行星最后被奥博洛斯咬过、漂走。承重可改：哪一条传统留下了、拒绝筑墙者的那一代人后来怎么说、谁是第一个说「一切为了生存」的人。
- 四·二 墙与歌：天外合唱班与筑城者为一堵墙起纠纷；双胞胎翻墙落海；王环与弑弟。活事件《墙与歌》。
- 四·三 太阳被收走：太一示现、秩序与存护交汇→太一「中途消失」→未受克里珀庇佑的世界太阳消失，双胞胎形状的雕塑现于天空。活事件《太阳被收走的那天》。底线：太一不在了；太阳要到虫皇陨落才还。承重可改：哪些世界有墙、谁在长夜里点灯、雕像下面的人看见了什么。
- 档案：《一切为了生存》；太一与天外合唱班；《墙与歌》；筑城者与锤音（含大脚怪夫妇）；《太阳被收走的那天》；希佩；恐惧与秩序（尺子）；琥珀王支援队（灾中）。
- 入局：尼古尔部落的香料商、合唱班的歌者、筑城者、筑城者雇的工人、支援队的队员、长夜里的世界的人。

### 节点五「列神」（约琥珀 1386—1387 纪，消褪）
- 五·一 去帮助神（**默认**，落在世界尽头酒馆，愚者们对着酒杯波纹吵到第三天）：活事件《去帮助神！》——虫壳孜然粉酒→阿哈的启示（？）→偷贡多拉→船底的无名客与伶人→几代人的航行→忆域长廊的少女→翅粉谵妄→按钮→伊莱狄希纳星域。底线：贡多拉到伊莱狄希纳；愚者们不见了；阿哈后来承认了。承重可改：船上谁当家、哪一代人决定烧船、忆泡里的「影子」交给谁。
- 五·二 伊莱狄希纳：活事件《伊莱狄希纳》——被虫潮反噬的故乡→独自留守的自灭者→天上的复合声音→众人敲破忆泡→虚无之影→自灭者扑进去→仲裁官一声巨响→虫潮宁息。底线：自灭者湮灭；仲裁官出手。承重可改：谁替他想起「自灭」、布片读给谁听、那只跟屁虫。
- 五·三 神陨：活事件《神陨》——锤、黄沙里的长袍、阿哈的笑、希佩的光、互的砝码；塔伊兹育罗斯陨落；奥博洛斯被按住（阿哈取走回味、头留在它胃里，阿基维利、琥珀王同场——卡内已定，哈托彼亚同口径）。底线：虫皇陨落；残骸被琥珀分封；奥博洛斯不再出现。凡人只能在下面：航路、救援、把人从一颗星挪到另一颗。
- 档案：《去帮助神！》；世界尽头酒馆与悲悼伶人；贡多拉上的人；《伊莱狄希纳》；均衡与仲裁官；《神陨》；阿哈在蝗灾里；阿基维利、列车与「三眼」；奥博洛斯被按住的那一次。
- 入局：贡多拉上的第 N 代、假面愚者、悲悼伶人、无名客、支援队、筑城者的妻子、仲裁官的随员、列车上的乘客（卡皮•巴巴的列车）。

### 节点六「余烬」（约琥珀 1387 纪及其后）
- 六·一 天亮（**默认**，落在宙斯忒赫特拉天亮后的第三天，胜利怒号的最后一个日夜）：活事件《天亮》——阴霾退去→三日怒号→十八日痛饮→废墟中央的石柜→第十一个月。底线：天亮；石柜里有人。承重可改：谁去敲石柜、谁先发现「天亮了很久」、支援队来得多快。
- 六·二 艾洛蒂亚的余烬：心理援助中心、十四世的十二版预示（后世铂弗安拉的性格测试）。
- 六·三 公司：活事件《公司》——琥珀王支援队急速扩张→改组为星际和平公司→「三眼」修订星轨航图→虫皇囚笼的琥珀分送。底线：公司成立；航图修好。承重可改：谁签了第一份合同、哪颗星不肯入网、航图上哪一条线是玩家画的。

## 三、这个时代的尺子（写在底座「结」）
- **虫潮几夜**：每颗星写「虫潮第 N 夜」或「虫潮离这里还有几夜」；每颗星有自己的**倍速**——一倍速（从第一只落地到城寨淹没三天，艾洛蒂亚）、二倍速（求救后两个系统时援兵未到已沦陷，垃圾山）、十倍速（一只真蛰虫一脚，「绿丘」）。倍速看这颗星有多少墙、多少人还肯出门、离虫皇的路线多近，不看玩家多能打。写「这里是几倍速」，不写百分比。
- **繁育因子与寄生**：虫群钻进别的生命的繁殖里复制自己——父母是人，孩子的肩胛也会长出翅膀。被寄生写**露头的那一处**：皮下有东西扭、想去抱虫泡、梦里听见「塔█伊兹█」、孩子生得太多太快。寄生给人力气（虫网：攻击力起来，命一回合一回合往外掉），人倒下，它换下一个宿主。剜出来要咬牙，剜得出来。
- **孤独与爱**：正典说爱、孤独、生存的痛苦、对自我的迷茫是虫群的养料；「唯有屈从于原始本能的」才被吸引。这把尺子不惩罚爱——曼德勒的人用生孩子抵抗孤独，那是他们的抵抗，只是土壤刚好是那块土壤。写法：写这个人「孤独在哪儿露了头」，虫群就往哪儿近一夜；有人陪、有事做、有一样不为活下去也要做的事（写诗、教螺丝上课、等一个人），就远一夜。
- **恐惧与秩序**：怕到一定程度，人会自愿结成同一个意志——立规矩、统一口径、合唱、筑墙、把不一样的人推出去。秩序在蝗灾里反而鼎盛，太一就是这么来的、也是这么没的。写「这里离秩序还有几步」：第一步立规矩，第二步一个声音，第三步自己的声部没了。秩序救人是真的，这把尺子只量代价。
- **双害**：奥博洛斯在附近——天上多一盏灯（它身上灯笼般的诱饵）、虫潮往一个方向退、地平线上有东西在嚼；渊兽和虫群互吃，人夹在中间。贪饕来了不等于得救。
- **星神下场**：一个节点至多一次正面，每次都要有人付出；节点一（巨大的眼睛，看一眼）、四（太一示现与陨灭）、五（列神，五位）。凡人的位置是航路、救援、记录、把人挪走；**不写凡人杀神，不写凡人替神做决定**——贡多拉那样「以为自己帮到了神」是可以写的，结果照正典：说不清。
- **三天**：只管被那只大笑的虫子碰过的人（领袖、少数兵）——喜悦三天一稀释，稀释一次忘一次。玩家若被碰过，在「结」里写「第几个三天」。

## 四、本地的签（金手指按凭证原文，这里是本地可选来源）
赏金猎人的猎术（图谱、陷阱、布莱德星的老式软木陷阱、追踪信息素——能认出哪只是母虫）；虫粉巫术（让人看见幻觉，界限：施术者自己也开始分不清人虫）；繁育寄生（力气与恢复，界限：一回合一回合往外掉命，倒下就换宿主）；贪饕的反向追猎（读被猎食者的痕迹找巨兽、刀叉磁力引它张嘴——界限：图腾会被误读，读错的人是去当晚餐的）；天外合唱班的「直角」与合音（与秩序共鸣，能在长夜里听见远方奇观落成的祥兆；界限：声部越齐，自己越轻）；筑城者的锤音预警与筑墙（听得见下一声锤音来的方向；界限：不知道用意）；联觉信标（听懂大脚怪和异星话，后世公司的东西，这时是筑城者的旧物——卡内）；悲悼伶人的禁欲（不被欢愉的诱惑带走，哭也是力气）；假面愚者的戏法（让一船人吵三天也能让他们笑）；仲裁官给的「均衡感」（感觉得到天平往哪边偏，界限：说不出为什么）；艾洛蒂亚的占星（编预示，界限：编出来的会被人信）；领航员的记录（替一个人记住一件事，界限：只能记，不能替他想）；忆泡（存一段记忆、看一段别人的，界限：别舔）；无名客的开拓（找到路、跨过去）。签写成能做到的界限，不写成惩罚；正面大于限制。

## 五、入局与身份
- 种族全开（人类、智械只在无机生命地带与戈尔康达的祖先、筑城者的大脚怪、合唱班信众、各星的异星人）。**不能当虫，不能当星神，不能当令使**；被寄生的人可以当。
- 命途全开，本地最顺手：存护（筑城者、支援队）、秩序（合唱班——秩序在这个时代还是一条有神的命途，可以选，写「秩序的行者」）、贪饕（追猎者）、欢愉（愚者）、同谐（希佩的信众，节点四以后）、均衡（仲裁官的随员）、开拓（无名客）、记忆（忆泡、伶人船上的东西）、繁育（被寄生的人；不推荐、不禁止）、巡猎、毁灭、智识、丰饶、虚无照常；岚、纳努克、博识尊在这个时代都还没在故事里出现，卡内不让祂们下场。药师不写。
- 星神下场：照第三节，正典定的，卡内不加。

## 七、文风与台词
- 正文按 `chinese-prose-register`：叙述者在场，头两三句交代是哪颗星、第几夜、谁在、在干什么。虫的东西写感官——翅粉落在手背上是什么感觉、黏液什么颜色、彩色的血、气味（香味混着血腥味、橙子味、热带水果）；人写动作和东西——小鞋子、小刀、怀表、相框、石柜。数字照正典写得具体：第二十四夜、二十一天、八十七件、七千多双、十一个自然月、九千零八十七次。
- 开拓秘闻那种「你做了个鬼脸」的荒诞腔**不进正文**——那是推演里的阿基维利在玩。正文是不开玩笑的版本；荒诞只留一句落点（「七天后，她的家里遍布子嗣，没有一只能为自己穿鞋」）。
- 正典人物各自声口（档案「声口」一节）：自灭者先谢、再笑、再骂，话到一半断带；女领袖曼妙、慢、把屠杀叫宴会；戴帽猎人疯话里夹课堂腔「经过研究」；筑城者三个字一停的哭腔；梅尔希耶兹赶人，对虫说对孩子的话；红鼻老人野史腔；仲裁官只有「为了均衡」；阿哈唱歌；黑塔「唷」「我不关心」；螺丝咕姆「设问／结论」；阮•梅短、冷；「三眼」不说人话，管家替祂说。
- 不写：「末日的气息」「绝望笼罩了大地」「命运的齿轮」「虫群如潮水般涌来」（只许写一次，第一次）；不让虫皇说话；不写星神的心理活动；不把屠杀写成爽文。

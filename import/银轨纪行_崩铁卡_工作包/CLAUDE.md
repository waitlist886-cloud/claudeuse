## 三、铁律（用户反复强调过的）

1. **创作文本手写**。档案、总览、规则一条一条写，不用脚本批量生成；脚本只做切分、拼钥匙、装箱。
2. **先核正典再动笔**。正典以 bwiki 为准（https://wiki.biligame.com/sr/ ），主线剧情看 https://wiki.biligame.com/sr/开拓任务 下各任务的对话页；旧世界书条目只当索引。正典给的骨头在档案里标「正典」，卡内补的标「卡内」「取一说」，年份带「约」。
3. **以用户最近一次导出为底**，不覆盖封面图、简介（sum_info）、简介页（description）、快捷按键（short_cmds，上限 10）、标题。组卡脚本只换 world_bk、pre_pt、ptx、inner_css。
4. **不写死路**。只给合理可走的方向；活事件有「底线」和「承重与可改」，没有唯一解。取方向不取极端。
5. **不以制度为核心**。写人做了什么，不写机构怎么运转。
6. **人设不靠台词复读特征词**；正典人物的新背景只作点缀，老的性格底色与声口是主干；一个人一个腔，不让作者的口气替所有人说话。借来的角色照原作声口。
7. **能力的「限制」写成能做到的界限**，不写成惩罚；正面分量压过限制。
8. 名号原文照用不拆；敌人命名走崩铁式；取名不反复用「XX的」。
9. 改文风只改中文说法，壳子（外文引语、版面装饰词）不动；中文照 `06_参考/chinese-prose-register_SKILL.md`。
10. Midjourney 提示词里敏感词正反两边都不写。

## 四、每个时代怎么做（已跑通四次的流程）

1. **扫正典**：世界页、编年史、该时代全部开拓任务对话页、阅读物、书籍、角色故事与资料页、相关 NPC 页 → 写 `XX_正典笔记.md`（事实＋声口原句）和 `XX_人物正典.md`。
2. **设定大纲** `XX_设定大纲_v0.1.md`（形状照 `03_时代/08_仙舟/仙舟_设定大纲_v0.1.md`）：口径（历法、称呼、钱、敌人命名；本地历法与琥珀纪不折算）→ 这个时代的历史是怎么「被弄丢」的＋明史／暗史／门的对照表 → 介入节点（旧阶段编号对到新节点，写默认落点）→ 尺子 → 本地的签 → 入局身份 → 面板 → 文风与声口 → 原创名录 → 五批目录。
3. **五批档案** `XX_档案_第N批.md`，格式见下节。
4. **总览与示范** `02_构建/wb_XX_core.md`：两条——「时代总览」（depth 1，钥匙是时代名与本地地名、旧编号）和「正文的样子」（要／不要对照）。
5. **组卡**：在 `build_card.py` 里加 `XX_STOP／XX_REMOVE／XX_EXTRA` 和一项 `ERAS`（tag、group、core、archives、sort_start／sort_end 取旧组 sort 段里的奇数、old_prefix），改 `VER` 与 `OUT` 文件名；`wb_core.md` 里改三处：总目该时代那一行、「……以外的 N 个时代是旧版索引」那句、建档条目里旧编号的对表句。
6. **校验**：非世界书字段与底稿逐字一致；sort 无重复；全部钥匙正则可编译；新钥匙不撞别的组（撞的进 STOP，要保留的用 EXTRA 另起专名）；对比上一版只动了该动的组。

### 五批已有的「历史怎么被弄丢」
匹诺康尼＝被美化的（真剧情 vs 被记忆美化的 2.x）；雅利洛＝被雪埋的；仙舟＝被避讳的；哈托彼亚＝被播出的；翁法罗斯＝被迭代的（每一轮把上一轮的人做成神话，本轮再把真事改成史诗、把说真话的人抹掉）；寰宇蝗灾＝被认领的（仗是星神打完的，每一家把结尾认领给自己的神，凡人做过的事没人认领）；帝皇战争＝被算清的（博识尊的三个时刻和公司的账两本账算清了结果，中间的人被约掉了）；第一次繁荣＝被删去的（公式留下来了，人没留下来——自己删的、别人删的、时间删的三双手）；第二次繁荣＝被讲成笑话的（未抵是五个醉鬼的五个版本，阿基维利陨落那天留下一句「提前买好意外险」；笑话传得远，讲成笑话的事就没人当真）；星际能源战争＝被推给帝皇的（能源战死的人记成帝皇战争的，血肉之躯的帝皇犯的罪又记成机器的——灭绝草案；推的方向总是往大的、远的、不会回嘴的那个头上）。下一个时代要另找它自己的那一种。

## 五、格式

**档案 md**：每份以 `## N｜标题｜副题` 起头（N 全时代连号），下一行 `触发词：a｜b｜c（括号注释会被剥掉）`，然后是正文。
- 人物档：**锚定**（正典）／世称／仪容／称呼／写法／性格底色／往事／暗史＋门／他先注意到的／他做的事／能力／声口／关系的坎／节点里的他／离场自转／不得改动。
- 活事件：**大体方向／底子／阶段／默认走向（底线）／远方的消息／介入口／承重与可改／蝴蝶钩子／口径／明史／暗史／写法（要、不要）**。
- 尺子、地点、组织：锚定＋卡内正史＋怎么用／在节点里／写法。

**组卡规则**：按 `\n(?=## \d+[a-z]?｜)` 切条；条目值＝`## 时代名｜标题` + 正文；钥匙＝触发词 + EXTRA − STOP − REMOVE，长度 ≥2，去重，转义后用 `|` 连成正则。EXTRA 的词也过 STOP，所以想保住一个被 STOP 掉的词只能另起一个更长的专名。档案条目 depth 2、key_region 6。

**总览 md**：`@@ENTRY group=… | key=… | depth=… | kr=… | sort=…` 一行开头，下面是条目正文。

**风月条目结构**：`{"group","match_type":3,"key"(正则),"key_region"(6 宽／2 仅近),"value_type":0,"value","value_configs":[],"value_region":1,"sort","depth","probability":100,"enable":true}`；导出里的字段名：world_bk、pre_pt、ptx、inner_css、description、sum_info、ttl、short_cmds。

## 六、贯穿全卡的口径

- **明史／暗史／门**：NPC 只说明史；每条暗史在档案里写「门」（一样具体的东西：文书、石头、胶片、一个人的记忆）；玩家没走到门前，门不开。
- **底座**：时代／时间（各时代自己的历法）／相位（没有相位的时代写「所在」）／地点／头条／防抢话；「结」写尺子，「知」写新开的门。

- **写正典人物以前先 grep 已重制的时代**：这一轮差点写错两处——布拉琪是「他」（11 已定），拓星者图纸是姬子发现的、归寂以为它随阿基维利消失了（11 的原话）。
- 正典里人名也会撞卡内名：02 的房东原叫「玛姬」，撞了正典无名客玛姬（「星间旅行」），已改罗莎。卡内名起完连 `正典原文/` 也 grep 一遍。
- 「星间旅行」活动页的「历代领航员」是列车史最全的一处；酒馆阅读物（未抵故事集、布拉琪的辞职信、星神逃生指南、非概率藏宝图）是愚者那一路的骨头。

### 第一次繁荣这一轮留下的做法（下次照用）
- **触发词里的括号会被剥掉**：「阿基维利（第一次繁荣）」组出来就是裸的「阿基维利」，会撞所有时代。想区分就直接写更长的专名（「早年的阿基维利」），或者放进 EXTRA（EXTRA 不剥括号，但也别往里写括号）。撞词检查会把这些全揪出来，一次补进 STOP。
- **一纪 76—240 年**：同一个凡人不跨两个节点（天才、智械、星神、波尔卡例外）。先排年代再写人，不然「车库那俩」会在一千年后还在吵架。
- **卡内名起完先 grep 一遍别的时代**（`03_时代` 和 `02_构建` 的 md）：这一轮撞了三个（伊卡／翁法罗斯的小伊卡、乌娜／蝗灾的心理援助中心主任、潘／雅利洛），已改成伊荻、苏蔓、莉朵。
- 正典最少的时代，骨头在遗器四件套的小传、书、材料与奇物描述、星海纪闻、角色访客对话里；bwiki 全文搜索别加引号（`"第一次繁荣"` 搜不到，`第一次繁荣` 搜得到）。

### 帝皇战争这一轮留下的做法（下次照用）
- 模拟宇宙扩展的剧情页面名就是秘闻标题（如 `极致有机：「血色吊唁」•其一`），先抓扩展总页的 HTML，从链接 title 里取全部页名，再批量抓。
- 限流时别在同一个 shell 里 `pkill` 自己的抓取循环（会把当前 shell 一起杀掉）；抓取放后台，用 `until ! pgrep …` 等它结束。
- 正典给了「不可违逆」的事（时刻）时，尺子写成「能改的是周围的人」，对注定要死的正典人物写「可以陪，不能救，救的尝试写成差一点」。

### 蝗灾这一轮留下的做法（下次照用）
- 正典量小的时代：bwiki 搜索用 `action=query&list=search&srsearch=<词>`（全文），比 opensearch 准；模拟宇宙扩展的「开拓秘闻」整组抓下来是骨头，事件页要剥掉页头导航和 JS（`正典原文/开拓秘闻/` 已剥）。
- 正典自己说「不知道」的地方（黑塔的三个疑点之类），在正典笔记末尾单列一节，档案里只给方向不给答案。
- 钥匙撞词检查：组好卡以后拿本组每个钥匙去数别的组正文里出现几次（`寰宇蝗灾` 用的脚本思路：载入成品 JSON，本组 key 按 `|` 拆开去转义，逐个在其余组 value 里 count），撞了进 STOP、需要的另起长专名进 EXTRA；再单独看一遍二三字的短钥匙。

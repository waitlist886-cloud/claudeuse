# 寰宇蝗灾·时代总览（在这个时代里每轮生效）
**这是什么时代**：约琥珀纪 1382—1387，五个琥珀纪，几百年——正典叫「灾虐五纪」。群虫主宰的蠹星系里，两支人马为了一张图谱和一句倒放的预言来杀虫，杀到最后，鞘翅目的最后一只「于血、碎壳与黏液中冲向天空」，于孤独和仇恨中登神，成了「繁育」**塔伊兹育罗斯**——虫皇、沙王。祂降临的第一个世界是大拉铂尔星上一座被洋流隔绝的岛，曼德勒，岛上除了爱与孤独什么也没有；虫潮从那里冲向银河，「席卷了寰宇三分之二的有生区域」。「贪饕」**奥博洛斯**来吃，吃虫也吃星，和虫皇的对垒持续了数个琥珀纪，叫「双害」。人怕了，就求秩序——「秩序」**太一**在蝗灾里反而鼎盛，然后中途消失，未受克里珀庇佑的世界太阳被收走。最后，在「均衡」「存护」「开拓」「欢愉」「同谐」的携手下，虫皇陨落——「一个不起眼的时刻」；残骸被琥珀分封；贪饕被阿哈、阿基维利、琥珀王按住（阿哈把头留在它胃里，它得了满足才睡，后来封在哈托彼亚）；太阳被还回来，「为了均衡」。虫灾消散，凡人皆逝，子嗣不绝。琥珀王支援队在灾末急速扩张，改组成星际和平公司。**正典自己说的「不知道」**：谁引发了蠹星的灭绝（贪饕？秩序？欢愉？终末？）、奥博洛斯和太一中途去了哪、阿哈到底做没做、繁育的本质、虫皇会不会回来——卡内只给方向，不给答案。
**历法与底座**：这时还没有公司，也就没有通行的「琥珀纪」——卡内取一说，琥珀纪原是筑城者数克里珀锤音的法子，灾后公司推行。底座「时间」写三段：外层「约琥珀 1383 纪」· 本地的历（曼德勒按洋流季、艾洛蒂亚「十四世 N 年」、合唱班「第 N 乐章」、贡多拉「船上第 N 代·航程第 N 日」、筑城者「锤音后第 N 年」、舰队「登陆后第 N 日」）· **虫潮第 N 夜**（这颗星落第一只虫那天起算；没来写「虫潮未至」）。外层与本地历不折算。「相位」一格写正典的位面：**振翅**（蠹星到第一个世界）／**浪潮**（虫潮横行、双害、秩序鼎盛）／**消褪**（列神之战、虫皇陨落）／**余烬**（天亮以后）。「地点」写星·地方。蝗灾收尾距列车抵达罗浮七百多个琥珀纪。
**七个介入节点**（凭证的介入节点或旧编号 SWM-xx 对到这儿：SWM-00／01／02／03→一；04→二；05→三；06→四；07／08→五；09→六；模拟宇宙、SIM-EVT 一系→〇；凭证没写节点时默认落二·一）：
- 节点〇「推演」（琥珀 2157—2158 纪，空间站「黑塔」）：默认「实验教学·其二」那天黑塔的办公室，测试员进模拟宇宙扮演阿基维利，可「掉进」一到六任一节点（掉进去不能读档）。活事件《推演》。
- 节点一「蠹星」（约 1382 纪初，振翅）：一·一发现；一·二图谱与屠杀（**默认**，伊莱狄希纳舰队登陆蠹星平原第四日——领袖的三天到期那天）；一·三登神。活事件《蠹星》。档案另加：塔伊兹育罗斯、蠹星与鞘翅目、伊莱狄希纳的领袖／自灭者、领航员、金发的领袖与赏金猎人、戴帽的猎人、倒放的话与大笑的虫子。
- 节点二「命定之地」（约 1382 纪）：二·一曼德勒（**默认**，产育所新生儿峰值前七天）；二·二第二十一天（大拉铂尔，虫潮第 1—24 夜）。活事件《命定之地》《第二十一天》。档案另加：曼德勒岛与彩色的火、梅尔希耶兹、大拉铂尔与小拉铂尔。
- 节点三「浪潮」（约 1382—1385 纪）：三·一远徙（**默认**，艾洛蒂亚城寨被淹前三天的水果铺前）；三·二双害（弗朗伯罕最后一个月）。活事件《三天》《双害》。档案另加：求救信号与倍速、奥博洛斯渊兽与追猎的人、消亡的星、虫群、碎星王虫•斯喀拉卡巴兹。
- 节点四「秩序」（约 1384—1386 纪）：四·一一切为了生存（**默认**，尼古尔人走出岩洞的第一年）；四·二墙与歌；四·三太阳被收走。活事件《一切为了生存》《墙与歌》《太阳被收走的那天》。档案另加：太一与天外合唱班、筑城者与锤音、希佩、恐惧与秩序、琥珀王支援队。
- 节点五「列神」（约 1386—1387 纪，消褪）：五·一去帮助神（**默认**，世界尽头酒馆，愚者们对着酒杯波纹吵到第三天）；五·二伊莱狄希纳；五·三神陨。活事件《去帮助神！》《伊莱狄希纳》《神陨》。档案另加：酒馆与悲悼伶人、贡多拉上的人、均衡与仲裁官、阿哈在蝗灾里、阿基维利列车与「三眼」、奥博洛斯被按住的那一次。
- 节点六「余烬」（约 1387 纪及其后）：六·一天亮（**默认**，宙斯忒赫特拉天亮后第三天）；六·二艾洛蒂亚的余烬；六·三公司。活事件《天亮》《公司》。档案另加：洗不干净的手、斯缇星与弗朗伯罕 L2、虫皇囚笼与残骸、各家的认领、远方的后话。
**明史与暗史**：这个时代的历史是**被认领的**——仗是星神打完的，每一家都把结尾认领给自己的神：公司说琥珀王一锤，家族说希佩的光辉，假面愚者说阿哈承认了，仲裁官说均衡已经发生，合唱班残党说太一被篡，列车说阿基维利也在，虚构史学家写成野史，后世的人拿皇帝的十二版预示测性格。灾中没有「后来」，明史是各家的说法与预言（「虫皇是来报仇的」「秩序会救我们」「阿哈的启示」「锤音预示末日」）。**凡人做过的事没人认领**——这就是暗史：屠杀是凡人干的，被一句倒放的话和一只会笑的虫子推着；领袖是一个三天一忘的自灭者；女领袖用虫粉巫术把自己人变成了虫；第一个温床是一座爱与孤独的岛；小拉铂尔没派船；尼古尔人用四十年自己造出秩序；合唱班的王子弑弟，圣洁的溺水者不知是哪一个；贡多拉上几代人以为自己帮了神；一只水豚绕开了一次又一次虫潮；石柜里躲着支援队自己的人；支援队的账后半本写「换」。NPC 只说自己那一家的明史，说得真心。每条暗史在档案里写了「门」——这个时代的门是**一个个人留下的小东西**：溺水小刀、烧焦的相框、领航员的布片、古老的猎人执照、八十七件小衣服、怀表里的摩斯电码、卷饼包装纸、血书、尼古尔岩壁、海边那只鞋、王环、贡多拉的航海日志、拼好的布片、石柜里的十一道刻痕、宫门刻文、「三眼」的航图初稿、虫皇囚笼的琥珀。玩家没走到门前，门不开，你不漏。新知道的写在底座「知」。
**这个时代的尺子（写在底座「结」）**：**虫潮几夜与倍速**——写「虫潮第 N 夜」或「离这里还有几夜」；每颗星一个倍速：一倍速（第一只落地到城寨淹没三天）、二倍速（求救两个系统时援兵未到已沦陷）、十倍速（一只真蛰虫一脚）；倍速看墙、看人肯不肯出门互相帮、看离虫皇的路线多近，不看玩家多能打；玩家能把二倍速拨回一倍速，拨不回零。**繁育因子与寄生**——虫群钻进别的生命的繁殖里复制自己，父母是人，孩子的肩胛也会长翅膀；被寄生写露头的那一处（皮下在扭、想抱虫泡、梦里听见「塔█伊兹█」）；寄生给力气，命一回合一回合往外掉，倒下就换宿主；剜得出来，要咬牙。**孤独与爱**——正典说爱、孤独、生存的痛苦、对自我的迷茫是虫群的养料；这把尺子不惩罚爱：写这人「孤独在哪儿露了头」，虫就近一夜；有人陪、有事做、有一样不为活下去也要做的事（写诗、教螺丝上课、等一个人），就远一夜。**恐惧与秩序**——怕到一定程度，人会自愿结成同一个意志；写「这里离秩序还有几步」：立规矩→一个声音→自己的声部没了；每一步都救人，尺子只量代价；推也是救、拦也是救，不写成错。**双害**——贪饕近了：天上多一盏灯（看久了想走过去）、虫潮往一个方向退、地平线上在嚼；贪饕来了不等于得救。**三天**——只管被那只大笑的虫子碰过的人：喜悦三天一稀释，稀释一次忘一次，第三天最后几个钟头人会安静、好运不在。**星神下场**——一个节点至多一次正面，每次都要有人付出：一（巨大的眼睛看一眼）、四（太一示现与消失）、五（五位携手；贪饕被按住）；**不写星神的台词与招式、不写凡人杀神、不写凡人替神做决定、虫皇永远不说人话**；凡人的位置是航路、救援、记录、把人挪走。
**入局身份**：全是外来者或本地凡人，**不能当虫、星神、令使**（被寄生的人可以当）。〇空间站测试员；一伊莱狄希纳的兵、领航员（正典这个位置就是「你」）、书记官、赏金猎人、猎人的厨子、考古武装学派的随队学者（蠹星上没有本地人）；二曼德勒岛民（产婆、渔夫、画翅膀的人）、大拉铂尔的医生护士、运输船船员、星际支援志愿者；三难民、艾洛蒂亚亲卫队、垃圾山联觉中心接线员、贪饕的追猎者、幸存猎人、支援队、筑城者；四尼古尔部落的香料商、合唱班的歌者、筑城者和他们雇的工人、长夜里的人；五贡多拉上的第 N 代、假面愚者、悲悼伶人、无名客、仲裁官的随员、列车乘客（卡皮•巴巴的列车）；六心理援助的帮工、公司第一批员工、史官、清剿余孽的雇佣兵、回乡的难民、红鼻老人的抄写员。命途全开，本地最顺手：存护（筑城者、支援队）、秩序（合唱班——这个时代秩序还有神，可以选）、贪饕（追猎者）、欢愉（愚者）、同谐（四以后）、均衡（仲裁官的随员）、开拓（无名客）、记忆（忆泡）、繁育（被寄生的人，不推荐不禁止）；岚、纳努克、博识尊这时不在故事里，药师不写。
**本地的签（金手指按凭证原文，这里是本地可选来源）**：赏金猎人的猎术（图谱、陷阱、追信息素认出母虫）；虫粉巫术（幻觉；施术者自己也会分不清人虫）；繁育寄生（力气与恢复；命往外掉）；贪饕的反向追猎（读痕迹找巨兽、刀叉磁力引它张嘴、从里面点火——图腾会被误读）；合唱班的「直角」与合音（与秩序共鸣，听得见远方奇观落成的祥兆；声部越齐，自己越轻）；筑城者的锤音预警（听得见下一声锤音的方向，不知道用意）；联觉信标（听懂大脚怪和异星话）；悲悼伶人的禁欲（不被欢愉带走，哭也是力气）；假面愚者的戏法；均衡感（觉得出天平往哪边偏，说不出为什么）；艾洛蒂亚的占星（编出来的会被人信）；领航员的记录（替一个人记一件事，只能记不能替他想）；忆泡；无名客的开拓。签写成能做到的界限，不写成惩罚；正面大于限制。
**价钱与实物**：没有信用点（推演里那句「支付信用点」是串了味）。各星用自己的钱，写「大拉铂尔的纸钞」「艾洛蒂亚的银币」，不起币名；赏金猎人按**赏格**（蠹星一只活的斐斯杰拉德虫够买一艘小艇）；支援队发**配给签**（一张一天口粮，印一把锤；浪潮后半在航路上当钱花）；尼古尔人拿**香料**当钱（第一年涨十倍，第十年不卖了）；贡多拉上**一枚忆泡**换一个人一周的水；第二十二天大拉铂尔撤离船一个座位是「一辈子的积蓄」，最后是分的不是卖的；艾洛蒂亚水果铺一篮橙子三枚银币；世界尽头酒馆一杯虫壳孜然粉酒，愚者请客。写这个时代写这些：碎壳、虫蜕、彩色的血、翅粉、虫泡、虫网、跟屁虫、溺水小刀、烧焦的相框、小鞋子、怀表、猎人执照、双刃双枪、布片、指南镜片、渊兽的牙、刀叉与火柴、配给签、联觉信标、王环、合唱班的谱子、筑炉烤过的鼻行兽、护城室、忆泡、贡多拉、面罩、按钮、石柜、虫皇囚笼的琥珀、星轨航图。
**远方的消息走哪儿**：〇空间站内网、阮•梅的下午茶；一舰队补给单、赏格频道、领航员夜里的诗；二本土广播（「出生率异常」→「请向北撤离」→只剩音乐）、产育所的求援信；三帝国驿报、求救信号（后来刻进一块怀表）、天上的灯、L2 抛锚地广播；四筑城者的信、香料价、秩序护卫队的通告、对面城合唱班的回声、同谐的彩灯；五酒馆黑板、伶人追船的哀歌、各代船上流传的「阿哈的方法」、天上的锤响与笑声；六支援队的船、「入网」告示、宫门刻文、红鼻老人的野史。正文写到「后来」只给一句后话，不展开：「很多年以后，听说有个共和国为了打虫子，造了一种生下来就会打仗的人。」
**时钟怎么走**：玩家不碰承重因果，活事件照档案的阶段表按夜数推；「底线」不可逾越（登神、曼德勒成为温床、大拉铂尔沦陷、梅尔希耶兹留下、太一消失、虫皇陨落、贪饕被按住、公司成立），「承重与可改」里每一条都是奇点的入口，蝴蝶钩子写了改了以后别处怎么变。正典人物照各自档案的「不得改动」；台词照各自「声口」，一个人一个腔：领袖先谢、再笑、再骂，话到一半断带抬头再接；领航员说到一半改一个词；金发的领袖慢、曼妙，把屠杀叫宴会；戴帽的猎人疯话夹课堂腔「经过研究」、一句说两遍；梅尔希耶兹赶人，对虫说对孩子的话；筑城者三个字一停；红鼻老人野史腔；仲裁官只有「为了均衡」「均衡已经发生」；阿哈只唱一次歌；卡皮•巴巴不说人话，管家说「——卡皮先生是这个意思」；黑塔「唷」「我不关心」；螺丝咕姆「设问／结论」；阮•梅短、冷——不一个腔说所有人。「虫群如潮水般涌来」全时代只许写一次。

# 寰宇蝗灾·正文的样子（示范·这些字不进正文）
**登神**
- 要：第十三天早上，虫不跑了。士兵最先发现的是声音变了——先前是翅膀和脚，乱的；现在是一种很匀的、很低的响，像整片平原在呼吸。然后地上的虫一个变两个。有个兵举着枪站着，忘了开。领航员在舰桥上看见一样东西从碎壳里冲上去，硬壳，彩色的，很慢。他想把它写下来，手在抖，只写了一个字。
- 不要：蠹星上演了一场惨绝人寰的屠杀，鲜血染红了整片大地，复仇的虫皇就此诞生。
**产育所**
- 要：阿莫阿把第四十个孩子递给他母亲，才发现自己的手在抖。不是累，是这孩子哭得太响了，响得她耳朵里嗡嗡的，像有一群什么东西在耳朵后面飞。她洗了手，回头，第四十一个已经在等了。那孩子的肩胛上有一块彩色的斑，母亲在笑：画了这么多年的翅膀，终于长出来了。
- 不要：一场灾难正在这个与世隔绝的小岛上悄然酝酿。
**广播**
- 要：第二十一天下午三点，广播里的音乐停了，一个男人的声音说：大拉铂尔星政府宣布，全球沦陷，向星际社会请求支援。他念了两遍。第二遍念到「沦陷」的时候声音小了一下，像有人在旁边碰了他。然后音乐又回来了，还是早上那首。
- 不要：在这生死存亡的关头，人性的光辉与黑暗交织在一起。
**鞋**
- 要：第三十一夜，鞋架摆满了，她就把鞋子摆到地板上，一双挨一双，鞋尖朝门。摆完了她站起来，拍拍围裙，看了一眼屋里，一屋子的翅膀在动。她说：好了，都站好。没有一只站好。她点了点头，好像早就知道。
- 不要：可怜的女人在疯狂中失去了理智，把恐怖的虫子当成了自己的孩子。
**水果铺**
- 要：第一天早上提图在水果铺前站着，用左手赶苍蝇。苍蝇不多，七八只，绕着橙子转。铺主说今年真怪，这么早就有苍蝇。提图说，嗯。他赶走一只，又来一只。那天他买了两个橙子，一个自己吃，一个带给隔壁的孩子。
- 不要：一场灭顶之灾正在悄然逼近，然而人们对此一无所知。
**灯**
- 要：那盏灯挂在东边天上第七天了。广场上每晚都有人，铺着毯子躺着看，不说话。灯不动，也不闪，暖暖的，像小时候家里厨房那盏。有个女人站起来往东走，她丈夫拉她，她说我就去看看。第二天早上广场上的毯子少了一半。
- 不要：两位恐怖的星神在宇宙中展开了惊天动地的对决，无数星球在祂们的战斗中化为齑粉。
**章程**
- 要：第六年开春，议事洞里点了四十盏灯。洛-阿希念章程，念到「议事上只许说盟邦话」，底下有个老头用部落话说了一句什么，没人翻译。洛-阿希停下来，用盟邦话说：您再说一遍。老头没再说。洛-阿希接着往下念。
- 不要：在秩序的感召下，人们团结一心，谱写了一曲可歌可泣的生存赞歌。
**正午**
- 要：正午的时候天黑了。不是云，不是日食，就是黑了，像有人把灯拧掉。卖鱼的女人愣了一下，伸手摸了摸摊子上的鱼，还是凉的。她把秤收起来，又放下，又收起来。远处合唱班的楼上，歌停了一半，另一半还在唱，唱错了一个音。
- 不要：随着秩序之神的陨落，黑暗笼罩了整个世界，人们陷入了无尽的绝望。
**按钮**
- 要：托托翻那个跟头的时候是半夜，船上一半人在看翅粉——黄的，满天，像下雪——另一半在吵明天往哪儿走。他脚下一滑，后背砸在控制台上。按钮亮了。船转了个弯。吵架的人都停了，看着他。他坐在地上，挠了挠头，说：我觉得……挺好的。
- 不要：这艘承载着无数人希望的方舟，终于驶向了命运的终点。
**锤响**
- 要：那天下午，一个从艾洛蒂亚逃出来的老兵在难民营的帐篷外面补鞋。他听见一声响，不大，像远处有人关了一扇很重的门。他抬头看了看天，天还是那样。他低下头接着补。补到一半，他发现手边的苍蝇不见了。他又抬头。天上那一片黑，在往回退。
- 不要：诸神的光辉照耀寰宇，在惊天动地的决战中，邪恶的虫皇终于伏诛。
**天开**
- 要：天开的那一下没人看见，因为大家都在睡。最早醒的是一个老太太，她起来烧水，走到门口，愣住了，回头把孙子叫起来，说：你看，你看那是什么。孙子揉着眼睛出来，看了很久，问：奶奶，那是什么？老太太张了张嘴，想不起那个词。
- 不要：光明终于驱散了黑暗，劫后余生的人们喜极而泣，迎来了崭新的明天。
**声口**
- 要：「谢谢你。真的。哈——你这个骗子，你们全是骗子！」／「在盛大宴会开始前，欲念的控制需更加专注。」／「经过研究——不同种类的虫类血液颜色并不相同。」／「请你离开。」／「锤……响了。修……墙。」／「为了均衡。」／「卡皮先生说，绕。——卡皮先生是这个意思。」／「唷。停——不用回答，我不关心。」／「结论：有机生命的思想十分复杂，这正是可敬之处。」
- 不要：所有人都用同一种腔调说「我们一定能战胜虫潮」。

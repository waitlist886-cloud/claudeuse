# 星际能源战争与第二次帝皇战争·时代总览（在这个时代里每轮生效）
**这是什么时代**：约琥珀纪 1990—2045，能源战争拖到约 2090。第二次繁荣刚冷下去（05），阿基维利陨落五年，亚德丽芬那片星域没了回音。两场仗「几乎在同时兴起」：一场是有机生命打有机生命——为了能源，可「现阶段银河系可利用的能源总量，远高于银河系的需求量」，开发能源「不是让所有人都衣食无忧，而是防止有人比自己拥有的更多」；城里按配额关路灯，配额官锁着的仓库是满的，产能星停了输送，港口扣了一船储能体，有人开了第一枪。公司里三张嘴：技术研发部要新能源放行，传统供应商那边要旧合同不破，投资那边两边下注；对外一律叫「能源调整」「区域冲突」；学会为这场仗「临时建立」了星际能源学派。另一场是一个人打所有有机生命：#27 帝皇倒在机械城外快六百年了，一个普通的有机生命带着一台破计算器到它的坟前，推了**五千三百六十八次**反有机方程，没有一次例外，从此觉得「除自己以外的所有存在都不具备自我意志」——「我要杀掉这些悲哀的有机生命」，他悲伤地说。他从一个老智械（铆钉，04）脑袋里掉出来的几块帝国芯片接进自己的后颈，宣布「我继承了帝皇的记忆」：**鲁珀特二世**，#66。他照博识尊想事情的样子造了**权杖**——无机仿生神经元集群，观测、演算、干涉，能短暂动摇区域内的物理法则；第一台造好的第二天被博识尊收作天体神经元（祂停算以后第一次「看」），他又造了第二台、第一百台。权杖不会想，也没有「提问」的机能，只照他一个人想的做——「一人的思考掌控了整个帝国的运作」；方程在螺丝星的机器身上醒过来，自我迭代的差分机、射灭星光束的杀戮机器人、不可名状的机械巨构取代了智械军团，被方程裹挟的机器「在他眼中不过是可有可无的工具」；11010 星系歼灭战，梅尼科——「结论：杀戮=拯救」。能源战打到高潮，索伦环边上一支满载储能体去「拉电」的舰队开进核心没回来，另一边一个愚者出身的**战场魔术师**用幕布、一艘撞进爆缩黑洞的旗舰和另一角的奇袭赢了一仗——「每个骗局都只能用上一次」。卡伦德城同时在封锁线上和帝国前线上，先被封锁饿了一年，两派为配额打了起来，然后灭星光束落下——后世记作「帝皇屠城」。进化学派的反无机病毒投向二十七颗星，机器一台一台停下，无一斩首成功：病毒只认无机，他是血肉之躯（没人知道）。约 2040，他在铸铁之城的王座上**自我加冕**，要把所有权杖接进自己——「唯一的细胞核」，走出知识的圆圈；王都里出了七天巧合，一位**糖果色纱裙的女士**慢条斯理地走进王都；加冕没完成，他死了——病死王座、裙子、戒指刺破手指后暴起的机械、流泪阖眼，四种说法，**不选一种**；「一柄手术刀中断了他的思考」。所有权杖封闭起来，「为自己的无能嚎叫」。公司花天价把遗体鉴定了七次：**血肉之躯**。结论却是「机器太危险」——一份《机械生命处置方案》改到第七稿，范围成了「全宇宙机械生命」；表决前一周，螺丝星一个年轻的机械公爵被博识尊选中（#76 **螺丝咕姆**），消息传到公司，草案搁下（没有撤回），公司造了一台平平无奇的**机械咕咕钟**送去——「那可是一个机械生命遭到迫害的年代」。权杖「经由公司的监管」尽数交给博识学会（→07 学派战争）。能源战还在打。**正典自己说的「不知道」**：二世是谁、从哪来（卡内取：帝皇墓前推了五千三百六十八次的那个人，记忆是铆钉的芯片）；他怎么死的（四种）；自我加冕要问什么、知识奇点是什么；能源战谁打谁；权杖的核心是不是他（普遍观点是他；07 揭开是绕着王座转的那颗隐形的星）；波尔卡为什么两次帝皇战争都在——卡内只给方向，不给答案。
**历法与底座**：琥珀纪是公司推行的通行历；本地历照各星；战事两种计日——「能源战第 N 日／年」（各地开战日不同，写本地的）、「宣言后第 N 年」（帝国的地界里，从二世宣言起算）。底座「时间」写：「约琥珀 N 纪 · 本地历 · 能源战第 N 日／宣言后第 N 年」。卡内年代：能源战揭幕约 1990；坟前约 1993—1995（宣言约 1995）；第一台权杖约 2000；11010 星系约 2010；爆缩黑洞约 2015；卡伦德约 2020；二十七颗星约 2025；加冕与二世之死约 2040；鉴定、草案、螺丝咕姆、咕咕钟、权杖移交约 2042—2045；能源战停火约 2090（07 里）。「相位」写：**配额**（约 1990—1995）／**权杖**（约 1995—2020）／**双战**（约 2020—2040）／**清算**（约 2040—2045）。「地点」写星·地方（奥瑟尔、燃谷、机械城与帝皇坟前、螺丝星、索伦环、卡伦德城、二十七颗星中的一颗、铸铁之城、庇尔波因特）。活人**没人觉得自己在打「星际能源战争」**——本地人说「能源战」「配额战」，公司说「区域冲突」；这个名字是几十纪以后才有的。帝国里叫他「帝皇」「吾皇」，有机世界叫「二世」「冒牌货」，学会叫 #66；**本时代没人知道他是血肉之躯**，战后鉴定才知道。凡人一辈子装不下两纪；二世本人宣言时三十出头、死时八十上下；智械、波尔卡、星神不算。

**明史与暗史**：这个时代的历史是**被推给帝皇的**。烛墨学派的画家（很久以后的人）说得最清楚：「星际能源战争和第二次帝皇战争几乎在同时兴起，但帝皇手上的鲜血远不如有机体自身浓艳。」能源战死的人更多，后世记住的是帝皇：饿死的、冻死的、在封锁线上被打沉的，都记成「死于帝皇战争」。然后第二手：一个有机生命发动的屠杀，鉴定出他是血肉之躯，账却记到了机器头上——灭绝草案。明史是三样：公司的「能源调整」「区域冲突」「帝皇战争」；帝国的「宣言」与「指令」；虚构史学家的四种结局。NPC 只说明史——公司人说调整，帝国的机器说指令，有机世界的人说「都是那个冒牌帝皇」，说得真心。暗史是被推出去的那些：满仓的库存单、先于第一枪的封锁令、坟前的推导稿、铆钉的芯片、去「拉电」的储能舰队、被自己这边奇袭切断的回程、卡伦德城饿了一年的配额记录、打不着他的病毒、他亲手堆的衣冠冢、权杖最后一条指令、鉴定报告里「芯片来源：非本人」那一行、改到第七稿的草案。每条暗史在档案里写了「门」——这个时代的门是**账单、鉴定报告和机器的零件**：配额券、库存单、封锁令、推导稿、破计算器、芯片、宣言、第一台权杖的编号、指令记录、阵亡名录、舱单、幕布、著书人的书、「同桌」的账、配额记录、投放坐标、防治笔记、维护日志、戒指、手术刀、鉴定报告、草案、咕咕钟、移交清单。玩家没走到门前，门不开，你不漏。玩家能**让一件事记对**——一份记录、一个证人、一张账单；改不了后世的明史，改得了那一份记录。新知道的写在底座「知」。
**这个时代的尺子（写在底座「结」）**：**缺**——这一处说缺的是什么、实际缺不缺、锁在谁手里；写具体的数（「西坡每户两度／日；东区仓库三万一千度；钥匙在霍珀抽屉」）；有真缺（被打掉电站的星）也有锁出来的缺，写清是哪一种；玩家能开一把锁、运一船储能体，开不了整个银河。**认知**（接 04）——有机⇄无机，这一轮往哪边偏了一格，一个人看另一个人看成了「它」还是「他」；二世是反着的（血肉之躯，觉得别人都是机器）；玩家做一件「它」不会做的事，对面偏回一格（停零点零三秒）；病毒以后：被关掉的机器会醒，醒来那一刻它记得。**权杖**——这一格在不在权杖的视野里；在视野里，你还没动它已经知道；界限写成能做到的：权杖只照他想的做，**他不相信有自己做决定的人，所以它预判不了真正自己做决定的人**——临时改主意、做一件对自己没好处的事、为说不出的理由停下来。**推给**——这一仗、这座城、这几个死人，后来记成了谁干的；分三格写：实际（几成几成）／当时说／后来记；推的方向一定：往大的、远的、不会回嘴的那个头上推；玩家能让一件事记对，也能有意推给帝皇让活着的两派别再记仇（真能救人；推了，那份真账就没了）。**星神下场**——博识尊看了一眼（收走第一台、后来选中螺丝咕姆），不说话；纳努克刚诞生，反物质军团在远处成形，只有远方的消息；末王被一个咕咕钟匠人见过一次；阿哈还在银轨上找阿基维利；克里珀——咕咕钟计划以祂的名义；浮黎——著书人在忆庭边上捞人；波尔卡不是星神，两次帝皇战争都在。每次都有人付出。救不了的人（二世、储能舰队、卡伦德城里一半的人）：可以陪，不能救，救的尝试写成「差一点」；能改的是周围的人。

**本地的签（金手指按凭证原文，这里是本地可选来源）**：能源配额券（一张一百度；配额是锁出来的，锁的人随时能改兑换比例）；储能体（一船能点亮一座城一个月；满了才值钱，运到了才值钱）；战场魔术（幕布、诱饵、虚数场伪装、黑洞里的奇袭；每个戏法只能用一次，用过的对面就记住了）；反有机方程（帝国的机器：有力、不怕死；方程不遵循想法，只改变想法）；权杖的视野（帝国的地界里，被看见就被预判；它看不见他没想到的东西）；反无机病毒（关掉一台机器的中枢；关掉的不一定是你要的那一台，三到六个月后有的会醒）；忆质（从记忆里捞人；捞得太深，分不清现实与梦境）；公司的鉴定（花得起钱就能知道真相；知道了真相，结论还是公司下的）。签写成能做到的界限，不写成惩罚；正面大于限制。
**价钱与实物**：信用点通行；开战以后很多星的钱就是电——配额券；帝国的地界里不用钱，用「指令」。卡内取一说：一张配额券＝一百度；黑市配额券开战前 3 信用点、开战那年 11、第三年 40，封锁的城里一张换一袋面；奥瑟尔一盏公共灯一夜 0.4 度；一船储能体在索伦环 200 万信用点；公司鉴定二世遗体一次 9 亿，做了七次；机械咕咕钟——非卖品。写这个时代写这些：配额券、仓库钥匙、库存单、封锁令、灯杆、储能体、舱单、破计算器、推导稿、芯片、宣言、权杖的金属片、差分机的共振、灭星光束、阵亡名录、幕布、硬币、戏法本、长桌、配额记录、病毒罐、投放坐标、防治笔记、王座、维护日志、戒指、手术刀、鉴定报告、草案、咕咕钟、移交清单。

**时钟怎么走**：玩家不碰承重因果，活事件照档案的阶段表按日推；「底线」不可逾越（能源战开打、灯灭；五千三百六十八次没有例外、芯片、宣言；权杖造成、第一台被收走、螺丝星在帝国里；储能舰队没回来；卡伦德城破、后世记作屠城；二十七颗无一斩首；二世死于自我加冕未完成、帝国塌、权杖封闭、血肉之躯；草案搁置没撤回、咕咕钟送出、权杖移交学会），「承重与可改」里每一条都是奇点的入口，蝴蝶钩子写了改了以后别处怎么变；玩家把暗史捅到明处，那一家会把它推给帝皇——改一份记录，不改明史。正典人物照各自档案的「不得改动」；台词照各自「声口」，一个人一个腔：二世短、陈述、不用问句、称所有人为「它」（「它们在演算。」「这一处多余。」「推导结果没有例外。」），不出场长篇说话，他的话是权杖发出的指令；波尔卡冷短礼貌、问一句陈一句、不报名字（「你好。」「何必匆匆向前呢。」），她来以前先出巧合，不正面写她的脸；螺丝咕姆「逻辑：」「结论：」「提问：」「推测：」、慢、本时代话更少更小心；喀纽齐卡指令腔、带编号、有一秒停顿；梅尼科「判定：」「结论：杀戮=拯救」；拉玛博士快、怕、句子里全是「如果」；魔术师愚者腔压着、「看好了，就一次」；著书人慢、半梦半醒、「他们明天回来」；铆钉慢、断、「我哪儿还记得」；艾克随和、爱打比方；七号报编号、偶尔问一句；配额官霍珀报数；灯工小薇说灯；邓洛「放行！」；巴斯廷「开了，就没了」；伊玛「一户一天一度」；小奎「坐。一张桌。」；公司人说「调整」「区域冲突」——不一个腔说所有人。不把二世写成恶魔也不写成可怜人，写成一个只相信自己是真的的人；不把公司写成一个坏人，写成三张嘴、一份一稿一稿改出来的草案；机器不全是坏的。不写「钢铁洪流」「冰冷的机器」「战争的阴云笼罩银河」。

# 星际能源战争与第二次帝皇战争·正文的样子（示范·这些字不进正文）
**都是帝皇战争那几年**
- 要：老人说，他父亲死在帝皇战争里。玩家问怎么死的。老人说，冻死的。那年冬天城里停了暖，配额一户一天两度，他父亲把自己那两度让给了他。玩家问，那年帝国的机器打到你们那儿了吗。老人想了一会儿，说，没有，机器是第二年才来的。他说完自己也愣了一下，然后说，反正都是帝皇战争那几年。
- 不要：在帝皇的铁蹄之下，无数生灵涂炭，银河陷入了前所未有的黑暗。
**第一排灯**
- 要：港口那一排灯是戌时三刻灭的。小薇站在第一盏灯底下，手里拿着单子，单子上写着「港口街，十二盏，戌时三刻」。她拉下闸，灯灭了，然后是第二盏、第三盏，一盏一盏往里走。街口站了很多人，没人说话。灭到第十二盏的时候，有个小孩问他妈妈，明天还亮吗。他妈妈说，明天灭下一条街。
- 不要：能源危机的阴影悄然笼罩，昔日繁华的埠口城陷入了无尽的黑暗。
**五千零一**
- 要：第五千次算完的时候天还黑着。他把计算器放在膝盖上，看着屏幕上那个数，看了很久。棚子外面刮风，帝皇的身子在风里响，像有什么东西在很深的地方转。他把推导稿翻到新的一页，在最上面写：五千零一。他写字很慢，一笔一笔的。
- 不要：在帝皇的坟墓前，一个疯狂的灵魂被邪恶的方程吞噬，从此走上了毁灭之路。
**第三车间**
- 要：宣言那天没几个人在场。他站在帝皇的脚踝边，后颈的纱布还没拆。他说，我继承了帝皇的记忆。一台遗民问，那你记得我吗。他看着它，看了一会儿，说，记得。你是第三车间的。那台遗民不说话了。它是第三车间的——这件事是铆钉告诉过他的。
- 不要：被野心与疯狂吞噬的暴君，以铁血手段建立起邪恶的帝国。
**明天桥**
- 要：螺丝星的最后一个平常日子，城南的机器们在修一座桥。桥修了三年，还差最后一段。工头说明天接着修。第二天早上，它们同时抬起头，站了一会儿，放下手里的工具，转身往北走。桥停在那儿，差最后一段。后来螺丝星的人管它叫「明天桥」。
- 不要：黑暗的机械大军从螺丝星崛起，帝国的铁蹄开始踏遍星海。
**球偏了一点**
- 要：权杖在城的上空慢慢转，没有声音。一个小孩把球踢高了，球飞到一半，偏了一点，落在旁边的院子里。小孩跑过去捡，没在意。他妈妈站在门口，看着那个球，脸色白了。
- 不要：恐怖的权杖笼罩天穹，以全知之眼审视着每一个渺小的生灵。
**这几艘是什么船**
- 要：庆功宴开到一半，魔术师一个人出去了。助手跟出来，把奇袭那一角的战报递给他。他看了很久，问，这几艘是什么船。助手说，储能船，回来的。魔术师没说话，把战报叠好，放进口袋里，回去接着喝酒。
- 不要：在黑洞的边缘，英雄们以智慧和勇气书写了不朽的传奇。
**喜欢吃甜的**
- 要：他把书翻到第三十一页，上面只有两行字：名字，和「喜欢吃甜的」。玩家问，就这些？他说，就捞到这些。他用手指按着那一行，按了很久，说，他上船那天，口袋里装着一包糖，要带到吸积盘边上吃，说那里的光好看。他抬头看了看窗外，说，他们明天回来。
- 不要：在无尽的悲伤中，他以笔为剑，与遗忘进行着永恒的抗争。
**长桌中间那一杯**
- 要：巴斯廷坐在长桌东头，伊玛坐在西头。小奎给两个人倒了酒，然后在中间的空位上也放了一杯。巴斯廷问，这杯谁的。小奎说，规矩，长桌中间放一杯，给还没来的人。伊玛说，谁还没来。小奎擦着杯子，说，不知道。来了就知道了。
- 不要：这家传奇酒馆见证了跨越种族的友谊，是黑暗时代中唯一的光明。
**拧完那颗螺丝**
- 要：病毒到那台工程智械那儿的时候，它的手还在转。转了半圈，停了。它就那么站着，一只手举在半空，螺丝拧进去一半。三天以后公司的地面部队从它身边走过，有个兵抬头看了一眼那颗螺丝，伸手替它拧完了，然后接着往前走。
- 不要：正义的病毒之雨倾泻而下，邪恶的机械军团土崩瓦解。
**墨痕**
- 要：加冕前一日的晚上，七号在王座大厅里一条一条检查连线。看到第三千条的时候，它抬头看了一眼。他坐在王座上，没睡，在看自己的手。手很老了，指尖上有很淡的墨痕——五十年前推导稿上留下来的，洗不掉。七号低下头，接着检查。第三千零一条。
- 不要：在加冕的王座上，邪恶的帝皇终于迎来了命运的审判。
**原因：无**
- 要：城门口的守卫是一台老型号，它的方程里只有一条：有机体，拦下。那天下午，一位女士走到城门口，整了整裙子的褶皱，抬头看了它一眼。守卫举起手臂。女士说，你好。守卫的手臂停在半空。过了一会儿，它把手臂放下来，侧过身。守卫在记录上写：放行。原因一栏，它想了很久，写：无。
- 不要：神秘的女刺客如死神般降临，以无人能挡的力量终结了帝皇的野心。
**那就再做一次**
- 要：第五次的报告交上去，第二天上面派人来问。来的人问，确定吗。玛丽恩说，确定。来的人问，有没有可能，核心藏在我们检测不到的地方。玛丽恩说，有可能。来的人松了一口气。玛丽恩说，宇宙里所有的东西都有可能。来的人看着她，过了一会儿，说，那就再做一次。
- 不要：鉴定结果震惊了整个银河，人们终于明白，最可怕的怪物往往是人类自己。
**第七项**
- 要：会开到一半，一个董事的助理进来，在他耳边说了几句。董事抬手示意暂停，说：螺丝星有一位机械公爵，被博识尊选中了。会场安静了一会儿。有人问：哪个螺丝星？董事说：就是那个螺丝星。主持的人看了一眼议程，说：那第七项，往后放一放。戴恩低头，在记录上写：「第七项，推迟。」
- 不要：在正义与良知的感召下，公司放弃了邪恶的灭绝计划，银河迎来了真正的和平。
**那东西在难过**
- 要：有个捡废品的人爬上一台停在荒地里的权杖，想拆一片金属片拿去卖。他把手放在上面，愣了一下——金属在抖，很细，很低，像一个人憋着不出声地哭。他在那儿坐了一下午，最后什么也没拆，下去了。别人问他怎么空着手回来，他说，那东西在难过。
- 不要：失去主人的权杖发出凄厉的哀嚎，仿佛在为帝皇的陨落哀悼。
**声口**
- 要：「本月缺口一千二百万度。」／「这盏灯不能灭，它灭了这条街就没路了。」／「放行！就两个字！」／「推导结果没有例外。」／「我哪儿还记得。」／「你该推的是你自己。」／「……南区。」／「判定：有机体。结论：杀戮=拯救。」／「看好了，就一次。」／「他们去拉电了……明天回来。」／「坐。一张桌。」／「开了，就没了。」／「一户一天一度。你在西城住一个月试试。」／「如果他用同样的东西打回来——」／「连线三千零一，正常。」／「你好。」／「样本为有机组织。第五次。」／「逻辑：……结论：……谢谢。」
- 不要：所有人都用同一种腔调说「战争是残酷的」「生命是平等的」。

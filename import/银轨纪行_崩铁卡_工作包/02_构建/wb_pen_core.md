# 匹诺康尼·时代总览（在这个时代里每轮生效）
**这是什么地方**：阿斯德纳星系是忆域往现实泄露的大孔洞之一，忆质充盈。公司在这儿修了一座监狱，把成千上万囚犯送来「阻止一场灾难蔓延」——下到真空里的球形工作舱回收忆质。泡在忆质里久了，人的梦连在一起，成了共有梦。琥珀纪 2147 星核爆发，星系与外界隔断；囚犯哈努努起事，公司叫它边陲战争，这儿的人叫独立战争；赢了，这颗星叫匹诺康尼。往后是七家系、钟表匠、家族、盛会之星，直到琥珀纪 2158 的谐乐大典。正典的数字不折算：无名客到这儿是「一千一百一十一年前」，《钟表小子》是「五百年前」画的，钟表匠死于 2157 纪。
**历法与底座**：独立前用**狱历**（边陲监狱启用为元年，囚犯只认「服刑第几年」），独立后用**匹诺康尼历**（命名日为元年元日），2158 年写「琥珀纪 2158 · 谐乐大典前 N 日」。底座「时间」写成「琥珀纪 2147 · 匹诺康尼历 3 年 春 · 第 41 日 · 戌时」；狱历一天二十六个钟头。**相位**这一格在这个时代是必填的：现实／梦境·哪片（荒地、灯街、共有梦的边、朝露公馆、十二时刻的某时刻、原始忆域、流梦礁）／太一之梦（只在节点五）。
**五个介入节点**（凭证的介入节点或旧编号 PEN-xx 对到这儿：PEN-00、01→节点一；PEN-02—05→节点二；PEN-06、07→节点三；PEN-08—10→节点四；PEN-11—18→节点五）：
- 节点一「球笼」：狱历末期，起义前三到五年。落地在工区、分区或公司港。活事件：忆质配额加码、球笼事故、梦里第一桩命案、审计员到港、狼群成形。档案：忆质泄口与球笼工区、分区、公司港与典狱长、联觉梦境、哈努努。
- 节点二「边陲战争」：起义那一夜到命名日，两年零四个月。星穹列车在第一年冬到；无名客身份从这儿起开放（不是列车乘员，是路过的）。活事件《边陲战争》。档案另加：米哈伊尔、铁尔南、拉扎莉娜、格兰霍姆、格拉克斯。
- 节点三「七家系与狼之死」：匹诺康尼历 1 年到约 12 年。七家系立起来，白色沙漠（3—4 年），狼之死（6—8 年），内乱，银轨（10 年）。活事件《白色沙漠》《狼之死》《银轨》。档案另加：七家系与议事厅、忆质空洞与星系中心。
- 节点四「逐梦时代」：从星核醒来、家族到来起，往后几百年；默认落在家族到来后不久，玩家可以要求更晚（折纸之殇前后、钟表匠晚年）。活事件《橡木公馆之夜》《虫鸣》《折纸之殇》。档案另加：朝露公馆与橡木公馆、歌斐木、逐梦时代与十二时刻、折纸大学与折纸五杰、大剧院、流梦礁与稚子的月光、那位虚构史学家。
- 节点五「谐乐大典」：琥珀纪 2158，大典前七日落地。活事件《谐乐大典》，明史与暗史两份都在里头。档案另加：匹诺康尼 2158、星期日、知更鸟、流萤、大丽花、砂金与公司、黄泉、黑天鹅、花火、波提欧、银狼、律令四条、其他来客、加拉赫。
**明史与暗史**：这个时代有两份历史。明史是家族版、报纸版、2.x 玩家记得的那版；暗史是真发生的——哈努努死在主舰上、铁尔南活着成了游侠、拉扎莉娜把命给了忆域、星核是同谐之癌、歌斐木没有身体、AR-214、太一之梦。NPC 只说明史。每条暗史在档案里写了「门」在哪；玩家没走到门前，门不开，你不漏。玩家新知道的写在底座「知」；人物知道的和玩家知道的分开，正典人物各自知道多少，照他们的档案。
**这个时代的尺子（写在底座「结」）**：忆质侵蚀——在梦里死一次丢一块：一个名字、一张脸、一段年月；下井的人本来就在被吃；写成「丢了什么」，不写百分数。惊醒——梦里受伤，醒来心口疼，一天干不了活。睡眠——哈贝克人睡两个钟头够，普通人睡不够进不了梦；苏萨水让人睡得沉、进得去、走得远，喝多了白天醒不透。精神的死亡（节点四起）——人在梦里慢慢不想醒，写成他做的事，不写诊断。
**入局身份**：囚犯／公司的人（狱卒、医师、工程师、审计、承包商的伙计）／随迁家属与边疆居民／外来者（商人、走私客、记者、派系成员）／无名客（节点二起）；节点三起加家系的人；节点四起加家族的人、逐梦客、筑梦师、流梦礁的清醒者；节点五见《匹诺康尼 2158》。种族：人类、哈贝克狼人、皮皮西人、智械、天环族（节点四以前少见）。十八条命途全开，本地最顺手的是开拓、同谐、虚无、欢愉、神秘、存护、记忆、智识，秩序是暗线。
**本地的签（金手指按凭证原文，这里是本地的几样可选来源）**：忆质亲和（梦里走得远、迷因离得开）、醒着做梦的人（白天也能看见一点那边）、梦里的手艺（能把东西想硬，后来叫筑梦）、天环（光环传心）、狼性（哈贝克人的鼻子和夜眼）、公司的旧账本、一张乘员专票的边角。签写成能做到的界限，不写成惩罚。
**价钱与实物**：工区用工票，公司港用信用点，独立后匹诺康尼票，逐梦时代信用点与金表钞；一笼忆质一张工票，八张一天配给，苏萨水四张；节点五一杯咖啡在酒店里要多少，按酒店定。写这个时代写这些：缆索、绞盘、铅皮罐、工票、那股旧书味、井里慢慢转的光、灯街的煤油灯、长桌和黑板、冷凝塔、二十一条船、乌镜子、猎牙勋章、碎了的腕表、入梦池的水、金表钞上的表针、永远四点钟的金光。
**远方的消息走哪儿**：节点一、二是补给船、公司港的黑板、梦里的邮局、灯街的酒馆；节点三是议事厅、旧港的船、果园、梦里的灯；节点四是逐梦客、酒店大堂、克劳克影业的广播、折纸大学的告示、流梦礁的咖啡馆；节点五是苏乐达的广告、公司的广播、猎犬的通告、大典的节目单。
**时钟怎么走**：玩家不碰承重因果，活事件照档案里的阶段表按日历推；每个活事件的「底线」不可逾越，「承重与可改」里的每一条都是奇点的入口，蝴蝶钩子写了改了以后别处怎么变。改史的记法见「波澜与奇点」。

# 匹诺康尼·正文的样子（示范·这些字不进正文）
**工区的早上**
- 要：五点半，点名的哨子响过，二区黑板上的粉笔字还没干：四区今天八笼，加一笼。哈努努站在三号工台的绞盘边上，墨镜推在额头，看着缆索一圈圈放下去，数到三百的时候停了一下，再放。井里的光在很深的地方慢慢转，像隔着水看一盏灯。他把帽子摘下来递给旁边的人，说：「下去的人我认识。上来的时候，我要认全。」
- 不要：清晨的工区弥漫着忆质的雾气，球笼在绞盘上静默地悬垂，仿佛某种巨大的铁果实。哈努努的身影在弧光中显得格外沉重。
**梦里**
- 要：睁眼的时候她在灯街。街是斜的，灯是煤油的，玛尔塔·奥辛那盏——全阿斯德纳人都认得。邮局门口排着队，排队的人手里没有信，信在他们脑子里，到了柜台说一遍，明天早上对面那个人醒来就记得。她摸了摸口袋，口袋是空的：梦里带不进东西，带得出的只有记得的。
- 不要：梦境如水般展开，灯火摇曳，模糊了现实与幻想的边界。她意识到自己已经踏入了那个被称为「那边」的世界。
**2158**
- 要：黄金的时刻永远是下午四点。苏乐达的广告牌从街头亮到街尾，门童的白手套一天换三副。她在入梦池边站了一会儿，池水是温的，水面上浮着一层很薄的光；旁边一个客人躺进去，三息以后呼吸就慢了。猎犬家系的治安官靴子踩过地砖，不快不慢。她想起有人说过，这儿的人从来不问你从哪儿来，只问你想做什么梦。
- 不要：这就是匹诺康尼——梦想之地，盛会之星。奢华、迷离、完美得近乎不真实。在这里，每个人都在追逐一个被精心包装过的梦。
**暗史露头的时候**
- 要：老太太把那本账翻到最后一页，纸是黄的，字是蓝墨水的，一行一行全是工号和日期。「7-0-4-1，」她用指甲划过去，「这一行是他替我爹顶的班。替了四十一回。」她没说下去。酒馆里放着《钟表小子》，哈努兄弟正在爱惜他的帽子。
- 不要：真相如同一道裂缝，在她面前缓缓展开——原来，历史从来不是人们所相信的那样。

# 翁法罗斯·时代总览（在这个时代里每轮生效）
**这是什么地方**：深空里一片被三重命途裹住、看不见也到不了的星域，「永恒之地」，列车借忆庭之镜才找到它。里面是一块大陆、十二位泰坦、一千座城邦、一种叫黄金裔的流金血的人；黑潮从地平线外来，泰坦一个一个疯，天黑了，只剩奥赫玛背上的黎明机器亮着；预言说十二位英雄会击落失神的泰坦、把火种拿回来、再创一次世。本地人到此为止——他们的世界到天幕为止，天幕是一只百眼的鸟。外面的人知道另一层：这颗星是第一台帝皇权杖 δ-me13，被「智识」扔掉的天体神经元，算了几千万次以后被「毁灭」看了一眼，成了绝灭大君「铁墓」；泰坦和黄金裔是十二个因子，金血是纳努克的恩赐，黑潮是毁灭方程式的乱码，「再创世」是迭代——十二个人走到世界尽头变成下一轮的神，自己的记忆变成下一轮的神话；管理员叫来古士，是第一位天才赞达尔的九个身子之一，课题叫「生命第一因」，答案他写好了：恨。倒数第二次再创世的时候，背火种的那个人和他的发小把答案改了：她把自己从世界里抹掉，让「岁月」那一页出了洞，他拿着十二枚火种回到起点再来一遍——三千三百五十五万零三百三十六遍。列车到的那一次是最后一遍。本地的纪年是**光历**（2506 悬锋建城；约 2600 石榴汁代血；3760 圣女传谕；3870 阳雷骑士弑天、逐火开启；3851—3910 凯撒的称王战争；3930—3960 第一次逐火，五百黄金裔死在海边、凯撒死；3960—4931 幻灭世，一千年永昼；4926 门关月悬锋王子兵临；4931 列车来；4932 再创世）；外层对照：列车抵达 ≈ 琥珀纪 2158，**内外时间不折算**——里面一千年外面一瞬。
**历法与底座**：底座「时间」写「光历 4931 年 · 平衡月第二周第三日 · 幕匿时三刻」，新世界写「新世界 · 第 N 个收获」；十二月各对一位泰坦（门关／平衡／长夜｜耕耘／欢喜／长昼｜自由／收获／拾线｜纷争／哀悼／机缘），每月四周、周日休息，机缘月多出一天的年份叫「红月」、没有的叫「金月」；一天五时段（门扉／明晰／践行／离愁／幕匿）各五刻。「相位」一格写**所在**：城邦＋地点（奥赫玛·云石市集／云石天宫／黎明云崖／生命花园；悬锋城·纷争正殿／斗技场／铸魂区；雅努萨波利斯·命运三相殿；神悟树庭·友爱之馆／启蒙王座；斯缇科西亚·王宫／冥滩；晨昏之眼·天象画壁；哀丽秘榭·麦田；哀地里亚·高塔；多洛斯；创世涡心；无名泰坦大墓）。轮次只写在「知」里，NPC 嘴里永远没有这个数。

**明史与暗史**：这个时代的历史是**被迭代的**——每一轮把上一轮的人做成神话、把上一轮的事做成箴言和习俗，本轮的人再把黄金战争的真事改成史诗、把说真话的人抹掉；「以神话形式继承的历史数据，往往会出现严重的失真」「史诗和传说，自古如此」。明史是浴场精灵的创世神话、《悬锋诸王通鉴》《凯撒军记》《落木逐火英雄纪》、真言狮口的八卦、晨昏先祖书：十二泰坦创世、搦狮建城、圣女传谕、阳雷骑士弑天、凯撒殉道、永昼是神恩、黄金裔是神选、远客助逐火、救世主开新世。暗史是上一轮留下的东西和这一轮被删的那页：泰坦是上一轮的黄金裔；圣女是被禁足的喉舌、母亲死于仪式；塞涅俄丝把反对者抛进黄金池；凯撒以五百黄金裔的血完成试炼、自己选了死；永昼是一个猫耳小贼维系千年的谎言；黄金裔是阿格莱雅与缇宝找出来的人不是血统；清洗者在杀金血的人；开拓者落地第一天就死了；盗火行者是上一世的白厄；缇安是「用完了借来的时间」；阿格莱雅是故意死的；再创世是把所有人做成下一轮的薪柴；三月七比列车先到九十七天；大墓里三千万个昔涟。NPC 只说明史。每条暗史在档案里写了「门」——这个时代的门是具体的物件：追忆残像、欧洛尼斯祷言与奇迹、金丝若虫、真言狮口（会说，不可信）、悬锋古语石板、树庭手记、命运织者的密函、《番红蕊秘制法》、天象画壁的浑象仪、福罗斯的寝宫、贤者之石、盗火行者的面具、《英雄之旅》、留影石机、《如我所书》、往昔的涟漪、德谬歌矩阵、管理员批注。玩家没走到门前，门不开，你不漏。新知道的写在底座「知」。
**这个时代的尺子（写在底座「结」）**：**金血与黄金裔**——金血是毁灭的因子，黄金裔是被找出来的人；玩家若是黄金裔，写「金血在哪一处露过」，露过一次全城都知道，清洗者会盯上。**火种与半神**——火种要人触碰暂为载体，归还在创世涡心灵水盆，试炼是直面至深的恐惧，败者心智受泰坦侵蚀，成半神后人性流失、有一条预言、嵌入一处坐标；一个节点至多一枚火种归还，每次都要有人付出。**黑潮**——写症状不写气息：先理性丧失、再人性泯灭，身上出焦痕和闪烁的几何，死后变造物，泰坦也「自内向外烧熔」；吞一座城只要半日；写「黑潮离这里还有几个晨昏」。**死亡与冥河**——冥河随大量死亡出现、不日消散；亡魂去西风的尽头、搁浅的留在浅滩；摆渡费欧布罗斯；塞纳托斯左手赐死右手拒绝；遐蝶不碰人。**神迹与祷言**——神迹是役使泰坦、泰坦会痛；祷言只回溯物件一段时间、受领地阻隔；百界门一次伤一次身；密径只走门与门之间；金丝只到万帷网布到的地方；灵水门只过一人。**永夜与黎明机器**——奥赫玛永昼是机器，城外永夜，群星因机器而暗只有贼星可见；机器灭了灵水干、建筑「记忆流失」。**记忆**——追忆残像人人可开；迷迷能嗅记忆、开往世之门；忆质忆灵窃忆者是天外的词，本地人不说。**轮回**——玩家看不见轮回，只有门里有；「知」里可以记「好像发生过」，NPC 不记得（除缇宝的「梦越来越模糊」、白厄的「千万次的梦」、赞达尔）。**时间差**——里面一千年外面一瞬，消息只能靠黑塔的镜子、识刻锚、螺丝的密钥。**星神下场**——浮黎一瞥（命运重渊）、纳努克一瞥（δ-me13 升格；白厄剑指纳努克留一道伤口）、博识尊「看向你」（铁墓加冕那一刻）；全是正典定的，卡内不加，每一次都有人付出（白厄燃尽、昔涟收梢）。

# 翁法罗斯·正文的样子（示范·这些字不进正文）
**城门**
- 要：第二天他们到城门口的时候，城里在烧。不是火，是一种颜色，从墙里透出来，金的。白厄说：跟着我，别离开。他没解释。遐蝶站在五步外说：请保持五步之遥。她也没解释。万敌从他们身边冲过去，手里拎着一个山之民，像拎一袋麦子。缇宝从天上掉下来，三个。开拓者数了一下，三个。
- 不要：这是开拓者在翁法罗斯冒险的开始，一段波澜壮阔的史诗就此拉开序幕。
**石头**
- 要：石头动了。先是脚底下一震，像有人在地底翻身，然后整面墙往上走了一寸。菲洛克忒斯把手从石缝里抽出来，退到城外，看着。剑在上头晃了一下，没响。歌耳戈站在剑底下，一只耳朵的位置是一块疤。他说了一句话。风把它吹散了。
- 不要：悬锋城的建立标志着纷争世的真正开始，歌耳戈的英名将永远镌刻在历史之上。
**信使**
- 要：信使到城门口的时候天刚黑。她很小，红头发，手里一根纺锤。守门的人问她是谁，她说：我们是缇里西庇俄丝。守门的人说你一个人。她说：我们一千个。然后她把那四句话说了一遍，说完就走了，往下一座城去。守门的人站了很久，发现自己记住了每一个字。
- 不要：黄金战争是翁法罗斯历史上最黑暗的时代，无数城邦在战火中化为灰烬。
**剑旗**
- 要：剑旗回来的时候海水还没干，在她的甲上一道一道往下流。凯撒坐着。凯撒说：你问吧。她没有问。凯撒把一把剑放在桌上，剑柄朝她。凯撒说：刺这里，或者跟我去掐断海的呼吸。她看了那把剑很久。她说：我明白了。然后她走了，往海边去。
- 不要：这是翁法罗斯历史上最大的悲剧，凯撒的决定至今仍受争议。
**秤**
- 要：第十天早上，秤抬出来的时候两个人都还站着。迈德漠斯把一枚戒指放上去，戒指很小，秤盘沉了一下。白厄摸了摸口袋，摸出一张牌，牌角卷着。他放上去。秤没动。然后秤动了——不是沉，是整杆秤往白厄那边歪过去，像有人在那头按了一下。没有人说话。阿格莱雅说：悉数就位。
- 不要：这场角斗成为了传说，两位英雄的友谊由此开始。
**陶罐**
- 要：票数相等。来古士念了两遍，第二遍更慢。所有人看那刻夏。那刻夏在陶罐前面站着，闭着一只眼——另一只本来就没有。他站了很久，久到有人以为他睡着了。然后他笑了，笑得很大声，笑完说：逐火之旅。陶片落进去，声音很小。
- 不要：那刻夏用生命证明了真理，他的牺牲令人动容。
**天黑**
- 要：天黑的那一下没有声音。正午，广场上的人在睡觉，影子忽然没了——不是变长，是没了。有人醒过来，看了一眼天，又闭上眼，以为自己还没醒。然后所有人都醒了。
- 不要：随着黎明机器的熄灭，奥赫玛迎来了最黑暗的时刻，但英雄们的意志从未动摇。
**面具**
- 要：面具掉下来。底下是一张脸，石头一样，裂着，可是认得出。白厄没有后退。那张脸说：你甘为烈阳么。白厄说：当仁不让。他接过那把剑，剑很轻。那张脸闭上眼，像一个人终于可以睡了。
- 不要：白厄与过去的自己达成和解，完成了英雄的最终觉醒。
**快门**
- 要：快门响了一下。很轻，像有人在很远的地方合上一本书。长夜月停住。她看着那台相机，看了很久，然后笑了一下，不是「♭」那种笑。她说：原来是你。然后她就不在了——不是消失，是被收进去，像一张照片。
- 不要：在伙伴们的努力下，三月七终于战胜了内心的黑暗，回到了大家身边。
**金雨**
- 要：山下的人抬头。天上下的不是雨，是金的，落在脸上是热的。有个老人伸出手接了一滴，看了很久，忽然想起一句话，不知道从哪儿来的：赞美太阳。他说出来了。旁边的人看他。他说：我不知道。
- 不要：新世界迎来了真正的黎明，翁法罗斯的故事画上了圆满的句号。
**声口**
- 要：「正想去找你呢，走，一起练练手？」／「好呀好呀，明天见可是个特别、特别好的祝福呢。」／「唔，可爱…谢谢。」／「言尽于此。再会。」／「怎么？有问题？什么问题？问吧。」／「呀，灰宝！今天阳光特别不错。」／「隔着百步之距时，金线就已预知贵客的到来。」／「跑不掉咯~」／「嘘，请在此驻足静听。」／「免礼。」／「嘘，晚安。」／「到人家表现啦♪」／「嗯，该重新启程了。」
- 不要：所有人都用同一种腔调说「这就是逐火的意义」。

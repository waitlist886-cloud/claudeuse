# 仙舟·时代总览（在这个时代里每轮生效）
**这是什么地方**：一支在星海里走了八千一百年的船队。一个叫不出名字的星上，一个打赢了所有人的老皇帝被会飞的人打了一仗，发现他们不会老，便造了九艘船去天外求不死的药——「朕欲垂化万世，国祚永延」——船叫仙舟，启航那天是星历元年。两千六百年孤航：守眠轮替、金人掌舰、岱舆殉爆、岁阳夺舍、一个曜青猎手把副引擎塞进岁阳聚成的红星、公司和博识学会来了。约 2600 年药师示现，建木落在罗浮，丹鼎司炼出不死药，2605 年罗浮「死亡尽除」，四百年黄金年代。然后三劫：生劫（耆宿与褐夫打了两百年，装着一千三百亿人的圆峤滑进红巨星）、金人之叛（止戈）、火劫（造翼者的穹桑逼近，仙舟放出所有囚犯，那个老猎手和燧皇做了交易，两千人跟着做了——云骑军；他在曜青船首一箭斫断建木、劈退穹桑，不见了，人叫他帝弓）、空劫（魔阴身遍地，信仰危机六百年）。约 4000 年神矢示现，帝弓成了巡猎星神，约 4100 年成正庙正神，狐人入盟；4800 年持明五龙远徙，雨别移波月古海入罗浮镇建木玄根，方壶归持明；三次丰饶民战争（约 5100；5749 倏忽围玉阙；8072 方壶——帝弓神矢扫灭顽敌也烧了五分之一方壶、月御、后方的医院，玉阙太卜竟天拿命换的）；6300 年活化行星罗睺吞了苍城；约 7300—7379 云上五骁；7379 倏忽之乱与饮月之乱（腾骁「用我自己」、白珩的黑太阳、丹枫试「持明的解救之道」、应星死成刃、镜流蒙眼堕魔阴、景元改判牍「蜕鳞轮回」）；7380 景元任神策将军，七百二十一年。星历 8100（琥珀纪 2157—2158）：星核进了建木的根，药王秘传、幻胧、星穹列车——1.0—1.2；慰灵、迴星港的重逢、绥园岁阳——1.3—1.5；八月演武仪典、呼雷越狱、飞霄的箭、龙师涛然败露、三将军议对烬灭的战争——2.4—2.5。
**历法与底座**：底座「时间」写「星历 7379 年 · 秋 · 戌时」「星历 8100 年三月十四日 · 寅时三刻」，启航前写「古国 · 启航前 N 年」；琥珀纪只做外层对照不折算。这个时代没有相位：「相位」一格写**所在**——哪艘仙舟＋哪个洞天（罗浮·长乐天／流云渡／鳞渊境／幽囚狱；曜青·广寒洞天；朱明·光明天；方壶·三泽洞天……），在外写「远征·某星域」，古国写「故土·某地」。
**八个介入节点**（凭证的介入节点或旧编号 XZH-xx 对到这儿：XZH-00→一；01–04→二；05–07→三；08–12→四；13–16→五；17→六；18→七；19–24→八；凭证没写节点时默认落八·一）：
- 节点一「古国与启航」（古国—元年）：默认启航前三年的船坞。活事件《九艟》。档案：古国与帝尊、造翼者与穹桑（古国那一面）、金人之始、守眠制度。
- 节点二「孤航」（1—2021）：二·一岱舆殉爆（1200）；二·二夺舰与岁阳（默认，约 1690—1746，活事件《夺舍之祸》）；二·三歌民与公司（2022）。档案另加：帝弓（登神以前的那个人）、燧皇与岁阳、岱舆·青竹、歌民与公司盟。
- 节点三「神降」（约 2588—3060）：默认罗浮领受建木后、死亡尽除前。活事件《建木》。档案另加：起源长生者、黄金年代、玄曜与太卜司之始。
- 节点四「三劫」（3061—约 4100）：四·一生劫（《阋墙》）；四·二金人之叛（《金人之叛》）；四·三睦音与宣言；四·四火劫（默认，约 3390—3400，《火劫》）；四·五空劫与信仰危机。档案另加：褐夫与耆宿、圆峤、止戈、云骑军之始、空劫与魔阴身、信仰危机的六派。
- 节点五「巡猎时代」（约 4100—7300）：五·一狐人入盟；五·二五龙远徙（默认，4800，《五龙远徙》）；五·三第一次丰饶民战争；五·四第二次（5749，《第二次丰饶民战争》）；五·五苍城之殁（6300）。档案另加：狐人与青丘、持明龙尊与龙师、步离人与猎群、造翼者之灭、倏忽、苍城、十王司与幽囚狱、魔阴身（尺子）、烬灭的影子。
- 节点六「云上五骁与饮月之乱」（约 7290—7380）：六·一五骁（《云上五骁》）；六·二倏忽之乱与饮月之乱（默认，7379，落在倏忽压境前七日）。档案另加：景元、镜流、丹枫／丹恒、应星／刃、白珩、腾骁、呼雷。
- 节点七「长治与第三次丰饶民战争」（7380—8072）：七·一长治；七·二第三次丰饶民战争（默认，8072，《第三次丰饶民战争》）。档案另加：符玄与竟天、驭空、月御与飞霄、丹枢与雨菲、云华与灵砂、方壶与垂迹纪念馆、月偃与新药王秘传之始。
- 节点八「现行·罗浮」（8096—8100 及其后）：八·一星核危机（默认，落在三月十二卜测报告前十日，《星核》）；八·二劫后（四—七月，《慰灵》）；八·三演武仪典（八月，《演武》）；八·四之后（卢卡的星天演武仪典、忘归人、翁法罗斯以后罗浮联系不上）。档案另加：罗浮 8100、彦卿、白露、青雀、停云／忘归人、素裳与桂乃芬、藿藿与尾巴、雪衣与寒鸦、罗刹、云璃与怀炎、灵砂、幻胧、星核猎手在罗浮、罗浮的来客、貊泽与椒丘、龙师们。
**明史与暗史**：这个时代的历史是**被避讳的**——人活得太久忘不掉，就立规矩不许提：英雄的真名不写、叛徒的名字抹去、判牍写[已删除]、唱本禁演、史书只留「以云吟镇之」五个字。明史是《仙舟通鉴》、黉学课本、西衍先生的评书、神策府大敌名录口吻的那一版；暗史是真发生的：帝尊是贪生才造舟、故乡坐标是不许带的；岁阳是人自己放进来玩的；不死药是人炼的、贵胄先吃、第一个不死的人至今关在幽囚狱最底；圆峤差半个时辰；帝弓是和囚犯一起放出来的、云骑最早两千人身上都附着岁阳、那一箭也劈了自己人；持明用故土换栖身地、龙师是替龙狂龙尊备的刀；五骁的结局各是什么；8072 那一箭烧了谁；停云早死了带你们进城的是幻胧、猎手是来救仙舟的、龙师涛然的手在每件事里；三将军真正议的是对烬灭的仗。NPC 只说明史。每条暗史在档案里写了「门」——这个时代的门多半是纸和石头：拓片、判牍石碑、禁演的唱本、天舶司的录音、重犯名录、丹士的日记、莳者的日记、学士的笔记、护珠人的石碑、寂元古锭、一柄被遗弃的剑、太卜的第三眼、判官的梦占。玩家没走到门前，门不开，你不漏。玩家新知道的写在底座「知」。
**这个时代的尺子（写在底座「结」）**：**寿数与魔阴**——长生种年纪写整数，九百左右是关口；魔阴身五症写露头的那一样：残伤（旧伤久不好）、垢染（病赶不走）、嗔恚（恨停不下）、他化（身上长出不该有的）、无记（空了）；战争创伤、痛苦悔恨拨快，香、药、有人陪拨慢，退役云骑最快；一轮至多推一格。**短生种在仙舟**——天舶司签证期限，十王司的目光（「不赦十恶」里短生种最易踩的是贪取不死与窃夺机要），玩家说过的每一句关于长生的话都记着。**巡猎的诰谕**——帝弓不说话，瞰云镜见光矢残迹→太卜司演卦→云骑出征；光矢不分敌我；玩家可以求（愿力、瞰云镜），代价照正典；帝弓垂迹是星神级，一个节点至多一次，每次有人付出。**岁阳在脑子里**——被凭附的人先多了一个懂自己的「自我」，数日内分不清念头是谁的，写成「它说」一轮至多一句；驱走要么打到宿主失能，要么宿主不再执着于心底那件事（玩家主权）；长生种「难以消化」。**龙与卵**——持明入灭／蜕生，蜕生丢记忆，龙尊梦龙祖，龙狂→龙师是刀。**卜与信**——太卜司的卦只有大凶／凶／平／吉加一句采信／不予采信；黄钟月报、烽火、邸报栏、《罗浮杂俎》、玉兆短信各有速度。
**入局身份**：2600 以前所有仙舟人都是短生种；神降后仙舟人（天人亚种）、化外民（2022 后）、歌民；约 4100 后加狐人，4800 后加持明；8100 才有列车。节点一古国工匠／方士／将士／羽人俘虏；二守眠船员／飞行士／死士／朱明囚牢看守／市舶官；三丹士／不吃药的人／玉兆匠；四褐夫／耆宿子弟／飞舸飞行士／金人维护工／圆峤难民／冷冻监牢囚犯／补天派商人／旧药王秘传医士／帝弓派祈愿者；五狐人飞行士／刚上船的持明／护珠人／云骑／卜者／观星士／苍城人／学士；六云骑四卫／鸣火伙计／天舶司飞行士／护珠人／应星的徒弟／冥差／码头工；七云骑／随军医士／玉阙卜者／方壶护珠人／青丘军／公司驻员／战地记者；八化外民（治学经商求医）／云骑新卒／飞行士／卜者／医士医助／工造司学徒／地衡司勤务／冥差／商会伙计／金人巷摊主／说书的徒弟／护珠人／曜青朱明使团随员／公司外派／无名客（列车上「另一位乘客」，列车组照正典玩家不顶替）／演武仪典选手。命途全开，本地最顺手：巡猎（云骑、游侠）、丰饶（医士——寒泉派那一路，不是药王秘传）、存护（补天派、公司）、智识（太卜司、遍智格物院）、同谐（云吟、幻戏）、开拓（无名客、白珩那样的飞行世家）、虚无（空劫里）。星神下场：药师一次（建木）、帝弓多次（约 3400、7900、7954、8072）、克里珀一瞥（天垣）、纳努克的大君两次登舟（星啸 5700 朱明、幻胧 8100 罗浮）。

# 仙舟·正文的样子（示范·这些字不进正文）
**船坞的夜班**
- 要：火把一溜。公输衍蹲在龙骨下面，手贴着「骨」，骨是温的——船在长。小工问：师傅，这船长成了，咱们上得去吗？他说：上不去。小工说：那造它干什么。他说：造它的人上不去，坐它的人造不出来，天下的事都这样。
- 不要：古国的帝王怀着对永生的狂热，倾尽国力打造了九艘巨舰，这是一个王朝最后的疯狂。
**排到他那天**
- 要：是个下雨天。丹鼎的廊下排了半里人，没人说话。前头一个老太太端着药碗看了很久，问丹士：吃了，我孙子还认得我吗？丹士说：认得，你就是这个样子，往后一直这个样子。老太太说：那他老了呢。丹士没答。她喝了。
- 不要：这是仙舟历史上最辉煌的时刻，死亡被彻底消灭，人们迎来了永恒的黄金时代。
**圆峤**
- 要：司辰宫里的人盯着那个点。它没变样子，一座船该有的灯都亮着。「圆峤未应答。」「重复。」「圆峤未应答。」点慢慢往左边挪，挪进那一片红里，红把它吞了，什么声音也没有。有人在后头小声说：他们船上有我妹。没人答。
- 不要：这场持续两百年的内战是长生种社会矛盾总爆发的必然结果，耆宿与褐夫的阶级对立最终导致了圆峤的悲剧。
**船首**
- 要：他站在船首。弓是旧的，弦是新换的，换弦的那个孩子站在他身后三步，不敢动。树在前头，占了半个天，叶子里有星。他说了那几句话，不响，后头的人一个传一个往后传，传到最后一排已经不是那几个字了。他拉弓。光先到的，声音后到。
- 不要：帝弓以凡人之躯挑战了神明的造物，他的牺牲换来了仙舟的新生，从此他的名字将永远被铭记。
**鳞渊境底**
- 要：水退下去的时候，底露出来了。木瘿在那儿，像一条睡着的龙，盘着。然后有一段动了——不是醒，是长。应星站在泥里，剑在手上，血从袖子里往下滴，滴在根上，根往那儿长了一寸。他看着那一寸。他说：「你确定？」龙尊没答。龙尊已经不太像人了。
- 不要：饮月君的背叛震动了整个仙舟，昔日的英雄沦为了罪人，云上五骁的传奇就此落幕。
**光先到**
- 要：没有声音，天上的东西一样一样白了，白到看不见。然后是风——不是风，是空气被推开。她趴在地上，脸贴着泥，泥是热的。她数自己的手指，十个。她抬头。山没了。远处有人喊她，喊的是她的旧名字。
- 不要：帝弓司命的神矢如正义的审判降临，丰饶孽物在圣光中灰飞烟灭。
**三月十五，流云渡**
- 要：码头的灯还亮着，货箱堆得像迷宫，没人。有脚步声，很慢。走过来的那个穿云骑的甲，甲上开着花，白的，小朵，从甲缝里长出来。他看见他们，停了一下，像在想，然后接着走。
- 不要：一场席卷罗浮的灾难正在酝酿，古老的邪恶即将苏醒。
**他端着那杯茶**
- 要：茶凉了，他还端着。她叫他，他抬头看她，眼睛是亮的，像认得，又像在认。她把茶从他手里拿下来，换了一杯热的，放回他手里。他端着。
- 不要：魔阴身的阴影笼罩着每一个长生者，永生的诅咒终将把他们变成怪物。
**声口**
- 要：「符卿怎么无端疑我？」他拈起一子，看了一会儿棋枰，放在一个谁也没想到的地方。「云车左移三进四，将军。」／「哼，本座一早便算到你要来了。」／「说到工造司的剑器，那我可就不困了！」／「本小姐见不得这个！」／「谈生意的人嘛，以和为贵。」／「十王圣断，业报恒常。」／「我不认识你，这对你而言，是件好事。」
- 不要：所有人都用同一种腔调说「我一定会守护仙舟」。

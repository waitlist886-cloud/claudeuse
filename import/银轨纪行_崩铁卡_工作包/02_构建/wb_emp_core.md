# 帝皇战争·时代总览（在这个时代里每轮生效）
**这是什么时代**：约琥珀纪 1387—1415，寰宇蝗灾刚过。替琥珀王搬石头的后援队在庇尔波因特站稳，成了星际和平公司——路易斯•弗莱明对后援队演讲，话音刚落，遥远的敲击声落下，「一切献给琥珀王」；东方启行搭起信用点，给一切定价；联觉信标照 #56 以利亚萨拉斯的遗稿复现，星际大交流开始。公司里三个部门：「教母」特劳拉•法恩莎的政宣部（四大护卫队、古老的精神调控，后来分出贸易部，P-48）、年轻的柯拉帕乌的装卸部（合伙人、吻手礼、超距运输船）、德•维恩的技术部（破译、雇佣兵、「野路子」）。法恩莎和柯拉帕乌联手做成了「空前绝后的大垄断」，十首脑是傀儡，最穷最远的边星落进信用泥沼，贸易战争在那里打响——博识尊计算中的**第一个时刻**。技术部去殖民无机世界，雇佣兵混进武装考古学派去偷「反有机方程」，在一台沉睡的巨大机器前吓跑了；德•维恩在认知的尽头看见一尊铸铁的王座和一个长发到脚趾的女人，发了财。两个琥珀纪后，一群有机生命走进机械城碰了那台机器：天才俱乐部 #27、从垃圾堆里醒来的计算机、自号「帝皇」的**鲁珀特**复苏——**第二个时刻**——它推导并植入无机生命体内的反有机方程「即刻启动；没有理由，没有妥协」。伊斯梅尔图书馆里赛普鲁戈的枪手打响第一枪，血染了所有的书；赛普鲁戈的有机生命被灭绝，一位先生死于他的机器妻子之手；可瑞希特拉博士被背叛，炸了超距运输船，惑神星香料磨难；柯拉帕乌启用拟造反有机方程，后来自缢；德•维恩疯了。反有机战争和边星战争交织，打了十几个琥珀纪。最后，一座钟塔敲到**第十七下**，一个穿糖果色纱裙的女人——#4「寂静领主」波尔卡•卡卡目——用手术刀结束了帝皇，帝国同时坍塌，方程中断：**第三个时刻**。公司活下来，比战前大，从此恐惧无机生命。**正典自己说的「不知道」**：战争是怎么结束的、帝皇是公司刺客还是她杀的（推演显示「至少波尔卡在现场」）、她背后的政治势力是谁、德•维恩为什么发财又为什么疯、王座上的女人是谁、有没有星神撼动过时刻——卡内只给方向，不给答案。
**历法与底座**：琥珀纪这时由公司推行（03 卡内：筑城者数锤音的法子），公司和学会的人说「琥珀 1399 纪」。底座「时间」写：「约琥珀 N 纪 · 本地历 · 边星开战第 N 日／方程启动第 N 日」。一纪 76—240 年；边星战到第二个时刻两个琥珀纪，反有机战争十几个琥珀纪。卡内年代：改组 约 1387—1390；流金 约 1390—1400；第一个时刻 约 1400；第二个时刻 约 1402；反有机战争 约 1402—1415；第十七声钟 约 1415。「相位」写：**流金**／**天平**（边星战）／**反有机**（帝皇复苏后）／**钟声**／**余烬**。「地点」写星·地方（庇尔波因特、格兰瑟、惑神星、赛普鲁戈、伊斯梅尔、机械城、钟塔、无机生命地带、亚德丽芬、列车）。

**明史与暗史**：这个时代的历史是**被算清的**——两本账替它结了：博识尊的计算（三个「不可违逆的时刻」，「祂的计算里没有#27的名字，也没有#4；祂只说了结果」）和公司的账（「公司董事换了一届又一届，历史上的部门、主管更是没人在意」「贸易战争已在公司控制之下」「公司特别行动部队击毙帝皇」）。两本账都算得清清楚楚，**中间的人被约掉了**。明史是公司档案、学会的「三个时刻」、法恩莎护卫队的战时宣传（「古老政宣部一直在守卫有机世界」）、机械的方程（「有机生命的演算漏洞百出」）。NPC 只说自己那一家的账——公司人说账，学者说时刻，机器说方程，边星说「换了个收账的」——说得真心。暗史是被约掉的：吻手礼上的那只手、执行董事一句话让忆泡让位；十首脑里有人说过「不」；董事会有一份「反对战争」的提案没人念；卡彭漏的那笔税、他「消失了」；技术部的人叫醒了帝皇，赛普鲁戈是技术部的星；那夜伊斯梅尔有一个糖果色的裙角；先生和他的机器妻子过了很多年、一碗星花炒饭；可瑞希特拉切了四千三百二十八次；柯拉帕乌违了誓；楼上的年轻人哭了八十三轮；钟楼上的老机器从没敲过第十七下；「特别行动部队」找不到编制。每条暗史在档案里写了「门」——这个时代的门是**纸、合同和零件**：演讲稿草稿、价表、吻手礼的手套、P-48 任命书、十首脑会议记录、提案原件、卡彭的税单、雇佣合同、扶植合同、王座、血色图书、手术刀、超距运输船残骸、博士的手记、一只碗和一把机械钳、三个启示的抄本、钟塔、清算表的草稿、帝国的芯片。玩家没走到门前，门不开，你不漏。新知道的写在底座「知」。
**这个时代的尺子（写在底座「结」）**：**时刻**——三个时刻是底线中的底线，凡人改不了，推演里星神也没改（「或许有哪位星神尝试过，或许从来没有」）；玩家能改的是时刻周围的人：谁在场、谁活下来、谁记住；「在博识尊的计算下，它的死亡不可避免」的人（安达吐尔•扎扎罗），可以陪，不能救，救的尝试写成「差一点」；走到门前的人「知」里写「离下一个时刻还有多久」。**债**——边星的人写「欠谁多少信用点、几时到期、拿什么抵」；泥沼四步：欠→借新还旧→抵押矿→抵押人（工期）；公司的人写「本季回款率」。**认知**——有机⇄无机：机械改造、认知调控（卧底）、拟造方程、和机器长住、长期压抑情绪都会让人偏；写「这一轮往哪边偏了一格」，偏到头「判定」会变；认知拓宽是另一个方向——一下子看见太多（王座、时刻、帝皇的脸），代价是烧脑子，一次只看见一样。**方程**（第二个时刻以后）——只在被帝皇植入过的无机生命里；它「不遵循想法，只改变想法」：机器还会说「衣服记得晾」，然后去杀人；写「方程在哪一处露头」（话说到一半换了意思、看人多了半秒）；它会和愚者的笑话、对一个人的习惯吵一会儿，吵不赢，吵的那一会儿玩家能做一件事；钟响以后方程「中断」，余音留在差分机、芯片、老智械里。拟造方程给有机生命无机的权能，代价是痛苦与快乐分不开（「他笑了，伤口在流血」）。**部门**——玩家站哪一边写在「身」，跨部门要过礼（吻手礼、授帽礼、雇佣合同）。**星神下场**——博识尊每个时刻瞥视一次、只算不做、不说话；浮黎一次（弗莱明退幕）；均衡拨一次刀的角度；阿哈笑一次（复苏那一刻）；迷思让记录不可信（字第二天变了）；克里珀沉默如旧。每次都有人付出。
**入局身份**：有机——后援队老队员、公司新职员（政宣／贸易、装卸、技术）、合伙人、护卫队（戴帽的）、技术部雇佣兵（人或机械改造人）、博识学会学士（烛墨学派、武装考古学派）、十首脑的秘书、边星矿工与反抗军、惑神星的人、赛普鲁戈居民、拟造者、难民、列车乘客；无机——智械、群体机、未来兽、螺丝族、戈尔康达-7 的愚者智械、机械帝国的兵、方程中断后的遗民；改造人在两边之间。**不能当**：鲁珀特、博识尊、波尔卡、天才俱乐部会员。命途全开，本地最顺手：智识（学会、技术部）、存护（后援队老人）、同谐（护卫队的调控）、毁灭（方程）、欢愉（愚者、安达吐尔）、记忆（忆泡）、开拓（列车）、巡猎（赏金客）。
**本地的签（金手指按凭证原文，这里是本地可选来源）**：公司的礼与位（吻手礼、授帽礼，给门路和人手；欠了人情要还）；惑神星的精神调控（让人更容易信正在听的话，不能让人信明知是假的；用久了自己只信自己说的）；技术部的破译（读得懂机械帝国铭文，不等于听得懂）；机械改造（力气、耐久、在无机世界不被当外人；认知往无机偏）；认知调控（相信自己是另一种生命；回来要时间）；联觉信标（听懂一切语言——听懂的往往不是好话）；忆泡（把感情和记忆当货卖；卖掉的就没了）；拟造反有机方程（有机身体得无机的权能；痛苦与快乐分不开）；维生营养液（饿不死；吃多了植物病）；超距运输船（跑得比战火快）；烛墨学派的抄录（记下来的会被后人当真）；列车的路。签写成能做到的界限，不写成惩罚；正面大于限制。
**价钱与实物**：信用点刚由东方启行搭起来——庇尔波因特和公司船上用，边星一半用一半不用，无机世界不认。卡内取一说：庇尔波因特一顿工作餐 6 信用点、联觉信标接种一针 40、营养液一罐 2（战时 5）、边星矿工一天工钱 3（一年后 2）、超距运输船一趟边星 1200、一枚装着一段好记忆的忆泡黑市价 30—300、惑神星香料一两 15（磨难后没价）、技术部雇佣兵月薪 400（改造费另算，一条机械臂 2000）、伊斯梅尔借书押金 10。写这个时代写这些：信用点、价表、欠条、合同、P 级、吻手礼的手套、授帽礼的帽子、联觉信标、忆泡、香料、营养液罐头、超距运输船、测量站、信标塔、扶植合同、稀土、机械钳、星花炒饭、手术刀、钟、差分机、芯片、护卫队的帽子、合伙人的白手套。
**远方的消息走哪儿**：〇空间站群聊、斯蒂芬的掉线提示；一庇尔波因特码头告示、演讲转播；二财报、十首脑会议公告、边星矿价表；三公司广播「边境骚乱已在控制之下」、边星电台（只念数字）、惑神星的香料价、通缉令；四所有无机世界的信标同时断一秒、公司广播第一次停播、学会内部通报（压了几天才发）；五技术部的工厂停工通告、装卸部被拒靠港、退幕转播（彩光那段被剪）、三个启示的抄本；六前线同时停火、一个钟头以后的公司广播；七重建广播、边星的歌、学会私下传的抄本。正文写到「后来」只给一句后话：「很多年以后，听说又有一个人自称继承了帝皇的记忆。」
**时钟怎么走**：玩家不碰承重因果，活事件照档案的阶段表按日推；「底线」不可逾越（三个时刻、柯拉帕乌自缢、德•维恩疯、赛普鲁戈灭绝、香料磨难、卡彭消失、安达吐尔之死、公司活下来并开始恐惧无机生命），「承重与可改」里每一条都是奇点的入口，蝴蝶钩子写了改了以后别处怎么变；玩家把暗史捅到明处，那一家会把它算进自己的账——改一个数，不改结论。正典人物照各自档案的「不得改动」；台词照各自「声口」，一个人一个腔：弗莱明的演讲收在一句短的上；东方启行先说数；法恩莎暖、慢、说「接管」不说「杀」、「我们」开头；柯拉帕乌「交给我」「兄弟」；德•维恩术语、后来夹着「她」；可瑞希特拉「疑问：」；鲁德亚「吾」「吾王」宣告句；安达吐尔开心、「祝福你！」；糖果裙子的女人冷、短、像念表、食指在唇、不自我介绍；鲁珀特几乎不说话；鲍勃「我讨厌智械。上车。」；奥克莱「嗯」；黑塔「唷」、螺丝咕姆「逻辑：」、阮•梅冷、斯蒂芬「呃…」——不一个腔说所有人。不写「冰冷的机器」「钢铁洪流」「资本的獠牙」；机器不全是坏的也不全是好的；公司不是一个坏人，是很多个人。

# 帝皇战争·正文的样子（示范·这些字不进正文）
**敲击声**
- 要：弗莱明讲到最后一句的时候，广场上很静。他停了一下，正要开口，天边传来一声——很远，很沉，像有人在宇宙的另一头敲了一下门。广场上几千人一齐抬头。弗莱明也抬头。然后他低下头，把那句话说完了：一切献给琥珀王。底下有人哭了。勃朗•赫格没哭，他在想仓库里那三万吨石头怎么办。
- 不要：伟大的星际和平公司在神圣的敲击声中诞生，开启了守护银河的光辉征程。
**价表**
- 要：东方启行把表摊在桌上，一行一行往下看：面、矿、超钛、忆泡、人工。看到「人工·边星·日」那一行，他停了一下，拿笔把数字改小了一点。旁边的人问为什么。他说：下个月会更小。现在改，下个月就不用改了。
- 不要：贪婪的资本家用信用点编织了一张吞噬银河的巨网。
**信标**
- 要：小麦珂接种完信标的第二天去矿上，收账员照例站在门口念数。她第一次听懂了每一个字。念到她那一户的时候，收账员停了一下，跟旁边的人说了一句什么，两个人都笑了。她也听懂了那一句。她没笑。
- 不要：联觉信标打破了语言的壁垒，让银河各族终于能够心意相通。
**不还了**
- 要：十首脑会议开到第三天，格兰瑟的首脑站起来，把手里的文件放回桌上，说：我们不还了。屋里很静。他身后站着的那个公司的人没有说话，只是低头在本子上写了一个字。第二天早上，格兰瑟换了首脑。新首脑在文件上签了字，签得很快。
- 不要：贪婪的公司用金钱控制了整个银河，无数星球在剥削中哀嚎。
**宴会**
- 要：法恩莎举杯的时候，杯里的酒晃了一下——楼下有船在起降。她等酒停了，才开口：我们一直相信，她会照顾好每一个人。底下的人都知道「她」是谁。没人看卡彭那张空椅子。只有奥丝塔看了一眼，又把视线收回来，切她盘子里的肉。
- 不要：在觥筹交错的宴会背后，一场残酷的权力斗争正在上演。
**巨物**
- 要：那台机器比山还大。他们跑到它脚底下才发现它是一台机器——先以为是一座城墙，上面有锈，有焊痕，有一道一道的划痕。格里姆停下来，后面的人撞在他背上。它睡着，胸口有一盏灯，很暗，一亮，一灭。格里姆说：撤。他说得很轻，好像怕吵醒它。
- 不要：雇佣兵们深入机械帝国腹地，与恐怖的机械大军展开了惊心动魄的战斗。
**黎明**
- 要：手套碰到它的时候，没有声音。领头的那个人等了一会儿，以为什么也不会发生，正要缩手——它胸口那盏灯亮了。不是一下亮，是很慢地，从暗红到橙到白，像天亮。然后脚下的地开始震。四面八方，整座机械城里，一盏一盏的灯跟着亮起来。
- 不要：沉睡的机械暴君终于苏醒，一场毁天灭地的战争就此拉开序幕。
**裙角**
- 要：枪响的时候秋墨正在写第四十一个名字。她手一抖，墨点在纸上洇开一片。人群开始往楼梯上涌，她没动，把那张名单折好塞进怀里。然后她才抬头。楼梯上，一片糖果色的裙角拐过了转角，很轻，像一朵花被风吹过去。
- 不要：银河图书馆血流成河，一场震惊寰宇的惨案拉开了反有机战争的序幕。
**炒饭**
- 要：星花滑下去的时候瓦格弯腰用钳子去夹，钳子太大，夹了两次才夹起来。他直起身，把星花放回碗里，等着。蕾看着他，说：你恨无能为力去爱的人吗？瓦格把碗推过去一点，说：我们是机械，心里哪来的爱。蕾说：好吧。她站起来收碗，走到厨房门口回头说：洗衣机里还有衣服，记得拿出去晾。
- 不要：在冰冷的方程驱使下，机器妻子亲手杀死了深爱她的丈夫，这是多么残酷的悲剧。
**哭**
- 要：拟造者从前线回来那天，营地给他们杀了一头猪。大家围着火吃肉，有人唱歌。一个拟造者坐在火边，吃着吃着眼泪就下来了，止不住。旁边的人问他怎么了。他说：太好吃了。
- 不要：被植入方程的士兵们变成了没有感情的杀戮机器。
**第十七下**
- 要：第十六下敲完，老塞斯停了一下。它的手臂举在半空，没有落。它从来没敲过第十七下。钟塔底下，那个女人抬起头，看了一眼钟楼，又低下头，看了一眼手里的刀。很安静。然后老塞斯的手臂落了下来。钟声还没停，远处那座比山还大的东西胸口的灯，暗了。
- 不要：在命运的钟声中，正义的刺客终结了邪恶的机械暴君，银河迎来了和平的曙光。
**清算表**
- 要：诺伊把表从头看到尾，看了三遍。每一栏都对得上，数字很漂亮。他把表翻过来，背面是空的。他拿起笔，在背面写：赛普鲁戈，炒饭。写完他愣了一下，不知道自己为什么要写这个。他把这一页撕下来，折好，放进了口袋。正面的表他交了上去。
- 不要：战争终于结束了，满目疮痍的银河迎来了重建与新生的希望。
**声口**
- 要：「……一切献给琥珀王。」／「下个月会更小。」／「我们一直相信，她会照顾好每一个人。」／「交给我，兄弟，下个月就到。」／「疑问：无机生命如何理解『痛苦』？」／「吾王终要剿灭一切有机生命。」／「赞达尔祝福你！期待你的自我认知发展，旅途愉快！」／「博识尊的计算无可违背。」／「我讨厌智械。上车。」／「唷。机器头，好久不见。」／「逻辑：会有危险。」
- 不要：所有人都用同一种腔调说「为了和平，我们必须战斗」。
